**第三、四问最终优化的是同一个目标：在完整发现、清除全部目标，并取得“没有遗漏”的退出证据之后，让整局总虚拟耗时尽可能小。**

现有数据支持的方向也很明确：**P3主要减少定位与清除造成的绕路；P4同时减少全局覆盖成本，并处理少数非常昂贵的局部无信号分支。**

以下按已经完成并留下实验结果的版本整理；规划中的合并方案不算作已验证成果。

**一、先分清：我们究竟在优化什么**

\[
\boxed{
T=\frac{\text{移动距离}}{5}
+\text{换频次数}
+5\,\text{检测次数}
+3\,\text{清除尝试次数}
+2\,\text{成功清除次数}
}
\]

这等价于：清除失败一次3秒，成功一次5秒，移动另计。

| 指标 | 在优化中的地位 | 应当怎样理解 |
|---|---|---|
| **完整清除、有依据地退出** | 第一优先级 | 漏掉困难目标后提前退出，不能算更快 |
| **整局总虚拟时间 \(T\)** | 核心效率目标 | 包含搜索、定位、清除和必要的遗漏检查 |
| 平均时间/源 \(T/N\) | 题目报告指标 | 同一案例中与最小化T一致；不同案例N不同，不能只比较这个数 |
| 移动、检测、换频、清除次数 | 成本解释指标 | 用来解释究竟省了哪些秒 |
| 定位区域大小、认证清除比例 | 中间指标 | 更准确可能需要更多移动，未必更快 |
| 程序现实运行时间 | 执行约束 | 程序算几秒，与机器狗虚拟行动几千秒是两件事 |

例如，“900秒/源”表示平均每个源摊到15分钟虚拟任务时间。若一局10个源，总时间就是9000秒，即2.5小时；不表示程序真的运行了2.5小时。

P3、P4的区别在于取得信息有多难：

| 第一性原理问题 | P3 | P4 |
|---|---|---|
| 为什么会收不到信号？ | 可能无目标，或距离超过接收半径 | 还可能站在定向源的背面 |
| 怎样保证发现？ | 探测圆覆盖目标域 | 还要保证对任意辐射朝向都有可见测点 |
| 多测一次一定有用吗？ | 新位置通常能增加方位约束，但移动可能不划算 | 可能再次无信号，花了移动和检测费用却未明显缩小区域 |
| 什么才能保证清除？ | 一个合法清除点覆盖整个保守可行集，或执行有限光学覆盖 | 相同；光学清除不受发射方向限制 |
| 为什么清完了还可能继续搜索？ | 策略不知道真实总数 | 同样不知道，而且未知频道的定向覆盖更贵 |

还有一个容易混淆的概念：

| 名称 | 当前具体含义 |
|---|---|
| 题设模型 | 距离、半平面可见性、误差界、动作费用等硬规则 |
| 校准后的仿真模型 | 用官方数据约束场景组成，保留H1/H2等相容机制；尚未唯一恢复官方生成器 |
| 候选策略 | L1、NoSignal、1150米环、25点覆盖、路线重排等实际决策程序 |

**校准模型帮助筛选策略，几何证书负责保证安全，两者承担不同职责。**

**二、目前已经实现的策略，分别做了什么**

这里按机制归类，不把同一算法的几十组参数重复列成几十项“创新”。

| 已实现机制 | 实际做法 | 主要想节省什么 | 当前结论与使用情况 |
|---|---|---|---|
| 有界误差可行集 | 交会方位扇区，维护包含真实目标的外包区域 | 避免错误定位、错误清除 | 两条线共同基础 |
| 最近安全清除点 | 区域足够小时，寻找离机器人最近且能覆盖整个区域的清除位置 | 最后一段移动 | 已采用；不必总走最小包围圆圆心 |
| 主动测点选择 | 比较有限候选的移动与交会效果 | 定位移动、后续清除 | 已采用；尚不是完整剩余时间优化 |
| **L5降到L1** | 首次发现后，局部追加主动测量上限由5降到1 | 追加测量及前往测点的移动 | 主线已采用；有官方对照支持 |
| **NoSignal选点** | P4选点时纳入无信号分支的预计成本 | 无效测量与大区域清除 | 主线、侧线P4采用；概率权重仍是启发式 |
| 联合调度joint | 综合绕行距离，决定现在处理目标还是继续覆盖 | 搜索与清除之间的往返 | 保留；早期“发现即处理”“先扫完再清”整体较慢 |
| **P3收缩搜索环** | 原7站不变，将六边形半径从1558.85米缩到1150米等 | 全局巡访及部分服务移动 | 侧线采用1150米，有覆盖证明和实验支持 |
| **P4覆盖31点→25点** | 改善三角网格布局与巡访路线，保留定向覆盖证明 | 全局移动、未知频道检测 | 主线最新采用；是较大的收益来源 |
| 主线紧致光学覆盖 | 用当前可行区域生成28米网格，而非始终覆盖初始长条 | 光学尝试及其移动 | 主线最新P4采用 |
| 侧线旋转矩形覆盖 | 根据当前区域长宽、方向生成紧致网格，比较合法覆盖计划 | 细长区域中的无效清除路径 | 侧线P3/P4采用 |
| 服务排序与后缀重排 | 按区域投影估计服务绕行；清除后重排未访问站点 | 后续路线 | 侧线采用；更短后缀不保证每局总时间更短 |
| P4固定L2、1200米阈值 | 多允许一次局部测量，更积极处理绕行较远的目标 | 以测量换清除成本 | 侧线采用；单独增量很小，退步案例多 |

以下也有实现和实验，但**没有进入上述最终获选组合**：

| 探索机制 | 想解决什么 | 为什么目前不作为主推 |
|---|---|---|
| Fisher信息、信息增益 | 找定位信息更丰富的测点 | 信息更多未必抵消移动费用 |
| 短期rollout、试探清除 | 预演若干后续动作，尝试提前清除 | 尚无相对最新强基线的充分稳定优势 |
| 概率式清除顺序 | 让估计更可能命中的网格先被访问 | 分布假设不充分，部分实验退步明显 |
| 共享测量 | 顺路测量其他已知频道，避免专程移动 | 有工程实现，但当前获选配置未启用，不能算作已有收益 |

这些机制和证据边界见[历史策略汇总](D:/2026WorkExperience/CUMCM2026Problems/B_solution_side_research/selected_dataset_iteration_20260911/docs/prior_evidence.md)与[侧线最终证据](D:/2026WorkExperience/CUMCM2026Problems/B_solution_side_research/selected_dataset_iteration_20260911/docs/side_results_evidence.md)。

**三、怎样读全部实验，而不把不同实验混成一个分数**

| 实验阶段 | 数据规模 | 主要回答的问题 | 可以得出的结论 |
|---|---:|---|---|
| 第一轮官方正常求解 | 每题60局 | 原基线的成本、组成与反馈是什么样 | 建立官方性能参照 |
| 第一轮标准调查 | 每题20局 | 补充固定条件下的可见性、测角信息 | 用于校准，耗时不与正常求解混算 |
| 第二轮官方对照 | 每题基线30局、候选30局 | L1等改进能否迁移到官方 | 支持组合策略的平均改善 |
| 主线最新演练 | P3 15局、P4实际20局 | 新版本实际表现 | 有真实表现，缺少同期对照 |
| 侧线最新演练 | 每题10局 | 侧线组合能否完整运行 | 同样有真实表现，缺少同期对照 |
| 主线P4本地改进 | 1000世界、3200次执行 | 25点覆盖与局部覆盖的增量 | 三类场景分开确认，仍存在个例退步 |
| 侧线本地迭代 | 648世界、6576次执行 | 搜索环、覆盖、调度等组合效果 | 有新确认集和压力集，不能把重复执行当独立样本 |

主要官方批次合计335局，其中40局是调查局；早期接入测试另列。下面这些效率比较尤其值得记住：

| 比较 | 环境与设计 | 基线→候选平均T | 结果怎样理解 |
|---|---|---:|---|
| P3：L5→L1 | 官方，各30局同期分臂 | 5043.29→4400.64 | **平均下降12.74%** |
| P4：L5→L1＋NoSignal | 官方，各30局同期分臂 | 11371.88→10663.89 | **组合平均下降6.23%**，不能全归给NoSignal |
| P4：旧候选→25点＋新局部覆盖 | 新本地确认，三池共800世界 | 各池平均下降约15% | 全清，但31/800变慢 |
| P3：旧L1→侧线组合 | 新本地确认120世界 | 4461.87→3780.07 | 平均下降15.28%，6局变慢 |
| P4：旧31点L1→侧线组合 | 新本地确认120世界 | 10875.99→9643.02 | 平均下降11.34%，11局变慢 |

**这些百分比不能相加。** 对照、世界、模块之间有重叠和相互作用；侧线P4的11.34%也不是在主线最新25点之上的增益。

**四、最核心的数据：时间究竟花在哪里**

以主线最新官方结果为例：

| 费用组成 | P3：平均秒数／占比 | P4：平均秒数／占比 |
|---|---:|---:|
| **移动** | **3729.52／84.4%** | **7171.23／78.6%** |
| 检测 | 468.00／10.6% | 1367.50／15.0% |
| 换频 | 91.47／2.1% | 256.60／2.8% |
| 清除动作费用，含成功与失败 | 129.07／2.9% | 330.15／3.6% |
| **合计** | **4418.05／100%** | **9125.48／100%** |

这张表说明：**优化动作数量时，首先要看它们改变了多少移动。**

侧线P4就提供了一个直观例子：

| 相对主线最新P4的观察均值差 | 时间变化 |
|---|---:|
| 多走1717.06米 | +343.41秒 |
| 多检测45.6次 | +228.00秒 |
| 多换频27.9次 | +27.90秒 |
| 减少清除尝试 | −153.15秒 |
| 成功数不同的附加费用 | +0.10秒 |
| **净差** | **+446.26秒** |

虽然失败清除少了很多，额外移动和检测仍把节省吃掉了。这是费用分解，不是随机对照结论。

另外，P4平均88.3次失败的**直接费用只有264.9秒，占2.9%**；光学网格阶段的移动却有1637.4秒，占17.9%。所以“优化光学兜底”的重点应包括访问路径，而不只是调用次数。

**五、P3与P4的瓶颈并不相同**

| 关键观察 | P3最新官方 | P4最新官方 | 推论 |
|---|---|---|---|
| 局部测量反馈 | 200/200得到direction | 229次direction、32次no_signal | P3优先减路程；P4还要处理无信号风险 |
| 光学兜底目标比例 | 123/200＝61.5% | 203/261＝77.8% | 兜底常见，但比例本身不能代表性能差 |
| 最后清除后的平均尾段 | 0秒 | 406.77秒，占4.46% | 最新瓶颈不能全部归因于尾部 |
| 主要优化方向 | 测点、清除点与后续任务的衔接 | 全局覆盖＋昂贵局部分支 | 两题不宜统一增加测量次数 |

P4的局部分支尤其值得看：

| 局部反馈 | 目标数 | 占目标比例 | 失败清除总数 | 每目标局部服务时间 |
|---|---:|---:|---:|---:|
| direction | 229 | 87.7% | 614 | 220.59秒 |
| **no_signal** | **32** | **12.3%** | **1152** | **549.38秒** |

**12.3%的目标贡献了65.2%的失败清除。** 局部服务时间包括测量和清除移动，不包括之后返回公共扫描站；这是描述性分组，不表示消除无信号就能直接省掉两组均值之差。

最慢P4案例总时间11391.91秒，16个源全部定向。其中4个局部无信号目标承担208/283次清除尝试。该局最后清除后的尾段为零，说明它的慢主要发生在清除过程中。[成本与分支统计](D:/2026WorkExperience/CUMCM2026Problems/B_solution/results/next_iteration_review/main_evidence.json)

**六、进一步优化，应该把力气放在哪里**

| 优先方向 | 为什么值得做 | 具体改法 | 当前证据边界 |
|---|---|---|---|
| **P3减少服务绕路** | 移动占84.4%，局部测量全部有方向 | 吸收收环、紧致覆盖、服务排序；统一考虑下一任务位置 | 侧线组合有效，但压力尾部仍有退步 |
| **P4统一评分与实际清除成本** | 评分器仍用旧110点网格估算无信号成本，执行器已经更换 | 用当前清除器评价各测量分支的剩余费用 | 明确的实现错配；修正收益尚待实验 |
| **P4条件第二测** | 少数无信号目标很贵，普遍L2又拖慢多数容易案例 | 默认L1，仅在预计节省足够时再测一次 | 高价值待验证方向 |
| **P4保留25点，改善服务顺序** | 全局覆盖仍贵，侧线路线机制有本地收益 | 保留站点集合，重排未访问后缀，改善目标处理顺序 | 两条最新方案尚未直接同世界配对 |
| **16个频道已证实时结束发现阶段** | 已不可能有第17个源 | 停止寻找未知频道，转为处理已知目标；清完才退出 | 推理成立，净耗时收益待执行验证 |
| 光学网格形状与访问顺序 | 网格移动比失败动作本身更贵 | 少量旋转、各向异性网格、考虑结束位置 | 保留全覆盖；最短完整路线不保证最快首次命中 |

“第二次测量值不值得”，应该比较：

\[
\boxed{
\text{去测点的费用}
+\text{检测费用}
+\text{测后预计清除及接续费用}
\quad\text{与}\quad
\text{现在清除及接续费用}
}
\]

走200米再测约需45—46秒；沿28米网格走一步并失败一次约8.6秒，粗略要省约6步才值得。不能只比较“测一次5秒”和“失败一次3秒”。

已有参数实验也提醒我们不要继续盲目微调：

| 开发集中的单项变化 | 平均节省 | 变慢案例 |
|---|---:|---:|
| P3环半径1200→1150米 | 6.14秒 | 66/180 |
| P4绕行阈值800→1200米 | 14.22秒 | 88/180 |
| P4同配置L1→L2 | 46.78秒 | 105/180 |

因此，下一步最有价值的变化是：**从固定次数、固定绕行阈值和区域半径代理，转向用实际剩余任务费用做决策。** 原有完整性证明继续保留，经验模型只影响行动顺序与效率。

平均更快也要同时检查难例：主线新P4组合在800个确认场景中有31个退步，最大多花3611秒；侧线P3压力集平均改善，但P95上升。新的候选应同时报告平均总时间、变慢案例数和最坏退步，才能判断它是否值得替换当前方案。
