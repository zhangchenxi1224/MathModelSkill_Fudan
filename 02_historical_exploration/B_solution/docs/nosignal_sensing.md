# 阶段 2：把无信号分支纳入选点评分

实现：`src/bsolver/nosignal_sensing.py`。本变体只改变原有主动候选的排序，不修改冻结的 10 个核心模块或 `survey.py`。所有清除认证、20 m 距离界、110 点后备、局部循环次数上限和全局停机证据沿用原逻辑。没有全局 monkeypatch，因此不同变体可以在同一解释器中独立运行。

```python
from bsolver.strategy import SolverConfig
from bsolver.nosignal_sensing import NoSignalConfig, NoSignalSolver

policy = NoSignalSolver(
    client, SolverConfig(problem=4, local_measure_limit=chosen_L),
    decision_log="decisions.jsonl",
    nosignal_config=NoSignalConfig(directional_prior=0.5),
)
result = policy.run()
```

独立选择接口为 `choose_measurement_nosignal(knowledge, current, mode="active", bin_width_deg=4., radius_weight=2., *, config=None)`。只有 active 模式改变排序；fixed/estimated 模式原样回退。先完成阶段 1 的 L 选择，再用独立预注册场景配对比较 normal/nosignal。本文件的六局小基准仅诊断执行与代价，不用于选 L 或调先验。

## 1. 哪些是真正的保证

对同一个固定源，其可见测点集合是接收圆盘（全向），或接收圆盘与一个闭半平面的交（定向），因此都是凸集。所有历史正射频测点的凸包内位置都保证可见，返回 direction 或 near。这里的正测点包括 near，不包括仅有光学清除确认的点。

代码用有理数精确谓词处理已提交的有限浮点坐标，避免把凸包外一丁点的位置用正容差“吸收”为保证可见。凸包外只表示这个证明不适用，不能推出无信号。若采样预测与这个独立几何事实冲突，整次选择回退原选择器。

一、两个正测点的凸包分别是点和线段；原候选排除重复测量，因此简单给凸包外点统一惩罚通常只会给全部候选加同一常数。本变体额外构造少量相容假设，只用它们提供更细的启发评分，不据此删除可行区域或认证清除。

## 2. 小规模共享参数假设

`NoSignalConfig` 默认参数完整冻结如下：

| 参数 | 默认 | 硬限制 |
|---|---|---|
| `directional_prior` | 0.5 | [0,1]；Q3 实际采用 0 |
| `position_sample_count` | 7 | 1..7 |
| `radius_samples` | 1000、1250、1500 m | 3..5 个不同的合法半径 |
| `orientation_sample_count` | 24 | 1..24，均匀角网格 |
| `interior_fraction` | 0.75 | (0,1) |

位置取外包最小包围圆圆心及其到若干外包顶点的凸内插点，去掉完全重复的位置；实际点数可能少于 7。每个位置/半径组合取一个全向分量和有限角度网格上的定向分量。默认至多 7×3×25=525 组，允许的最大配置至多 875 组。

每一组固定 `(g,R,u)` 通过 `knowledge.compatible_hidden_state` 检查**全部**历史正观测、负观测、角度误差界及失败清除。不能在不同观测之间更换 R 或 u。策略只把自己生成的假设代入已观测约束，没有传入源真值。

设方向先验为 π，位置网格数 G、半径数 J、方向数 U。筛选前每个全向状态权重 `(1−π)/(GJ)`，每个定向状态权重 `π/(GJU)`；筛选后统一归一化。这样 24 个方向不会自然拥有全向分量 24 倍的先验质量。π 可由 fit 局的公开组成估计 `E[Ndir/N]` 传入；代码不会自行读取 development/confirmation 结果来更新它。

这些是有限网格的启发权重，**不是校准过的概率后验**。角网格可能错过可行的窄方向区间，半径网格也可能错过真实的窄半径区间。有效权重为零时直接回退原选择器，而不是认定无解或丢弃该目标。

## 3. 统一秒制评分

候选集合逐点、按原次序调用原 `candidate_points` 生成；每个候选的 direction 分支仍使用原 `direction_outcome_bound` 计算保守角度结果包围圆半径界 r(q)。有限假设在候选 q 处分为 direction、near、no_signal 三支，归一权重分别记为 p_d、p_n、p_0。

评分是

\[
J(q)=\frac{\|q-x\|}{5}+5
+p_d\frac{w\,r(q)}5
+p_n\cdot5
+p_0 C_{opt}(q).
\]

其中速度为 5 m/s，固定测量时间为 5 s，原 `radius_weight=w` 沿用默认 2。三个分支项含义为：

- direction：沿用原包围圆半径转行走时间的启发代理 `w*r/5`，不称真实剩余时间上界。
- near：原测点直接光学定位并清除需要 5 s。
- no_signal：若立即切换到既有有限光学后备，取整个剩余路径的保守成本上界。

同一频道各候选需要的频道切换成本相同，因此排序中省略这项共同常数。实际执行与总时间统计仍由 `RobotClient`/原策略完整计入。

计算 `C_opt` 时先生成原 110 点，沿用原“距整个保守外包超过 20 m 加裕量才可跳过”的规则；反向选择也与原代码一致。设保留 m 点，按实际顺序从 q 出发走完整保留路径长度为 D，则

\[
C_{opt}(q)=D/5+3m+2.
\]

真实源在外包且首次示向误差界有效时，至少一个保留点可成功清除；该成本放大为完整路径、最多 m 次光学尝试与一次激光清除。因此它是**立即执行该后备选项**的成本界，不是本策略未来继续主动测量后的总成本界。把它与采样权重相乘后的 J 仍是启发评分，不能当作全局最优证明或期望时间认证。

## 4. 控制流与可复核日志

`NoSignalSolver` 的 `_localize` 保留原局部循环所有出口，只替换选择器；新选择点必须属于原有限候选。失败/无信号仍更新原知识账本，接着按原 L 限制决定继续或后备。样本不参与 `_try_certified_clear`、`nearest_safe_clear` 或后备跳点判断。故原适用配置的有限终止和虚拟时间粗界仍成立。

每次选择日志含：全部候选与原 direction 半径界、原评分、三个分支权重与秒制分项、立即后备成本界、正测点凸包认证、相容样本数量/分量权重、原最优点和是否改选。样本为空等情况保存明确 `baseline_fallback_reason`。

结果增加 `nosignal_choices`、`nosignal_changed_choices`、`nosignal_baseline_fallbacks`、`nosignal_convex_mixed_choices`，并在开始/结束日志记录完整配置。选择结果中不写计时，以保证相同观测和配置得到完全相同的决策对象；CPU 时间由独立基准测量。

## 5. 实际小基准与限制

运行命令：

```powershell
& 'D:\st_python\python.exe' scripts/bench_nosignal.py --output results/nosignal_bench --max-snapshots 48 --repeats 2 --local-limit 2
```

六个预先写入脚本的本地场景包括 Q3 两个随机全向场景、Q4 两个随机场景及边界向外/切向两个场景，各 10 个源；误差场为固定 extreme。两个策略各跑一次，共 12 次。`L=2` 只是这一小诊断的固定值，没有替代阶段 1 的正式 L 选择。

从**基线轨迹**等间隔取 48 份观测快照，对两种选择器使用相同知识、位置和原候选；每份重复两次，交替计时先后顺序。2026-09-11 本机实测：

| 指标 | 结果 |
|---|---:|
| 全部快照实际改选 | 18/48，37.5% |
| Q4 快照实际改选 | 18/32，56.25% |
| 空样本等原选择回退 | 0/48 |
| 候选中阳性凸包内/外混合 | 4/48 |
| 原选择器平均耗时 | 46.22 ms |
| 新选择器平均耗时 | 51.83 ms |
| 平均增加 | 5.61 ms，约 12.1% |
| 原/新耗时第 95 百分位 | 70.06 / 78.81 ms |
| 12 次局级执行 | 全部完成并清除全部目标 |
| 真源落到外包外的记录 | 0 |

Q3 两局虚拟时间不变；Q4 四局新策略相对基线分别减少约 652、209、1668、805 s。**这只说明该候选确实改变了动作且值得进入预注册比较；六局不能确立优越性**。没有依据这六局更改 π、网格、L 或 w，也没有消耗阶段 2 的 development/confirmation 样本。原始配置/散列、逐局结果、观测快照和耗时均在 `results/nosignal_bench/`。

新增工作主要是至多 S 组状态对 O 条账本的筛选（O(SO)）、110 点对外包的跳过检查，以及每个候选对 S 个假设的分类。原有角度分箱与 MEC 计算数量不增加。分量网格仍可有系统偏差，所以上述选择概率和收益必须由独立场景、不同组成/半径/方向/误差场及官方演练进一步检验。
