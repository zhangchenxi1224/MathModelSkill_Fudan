# 标准调查协议 standard-survey-v1

实现位于 `src/bsolver/survey.py`，与冻结的 `strategy.py`、`knowledge.py`、`protocol.py` 分离。它接收既有 `RobotClient`，只使用公开响应。代码不导入模拟器、不访问隐藏目标数、坐标、接收半径、类型或朝向，也不会自行创建 HTTP 连接。

```python
from bsolver.strategy import SolverConfig
from bsolver.survey import SurveySolver, run_survey

result = run_survey(client, SolverConfig(problem=4), survey_seed=20260911001,
                    decision_log="case_decisions.jsonl", sample_count=2)
# 需要在本地评价器检查完整决策时，也可保存对象：
# policy = SurveySolver(client, config, survey_seed=seed, decision_log=path)
# result = policy.run()
```

`survey_seed` 必须在进入该局前预注册，且为整数；标准协议 `sample_count=2`。允许 0..20 是为了构造测试及明确登记的变体，不能把其他取值混称标准协议。新实例须从该局原点、频道 1、虚拟时间 0、尚未清除任何目标的状态开始；可以由调用方先执行一次 `/enter`。实例不可二次运行。对每个正式收集的演练案例，调用方应同时保存请求 JSONL、决策 JSONL、案例分组/种子和代码散列；整局所属 fit/development 划分由外部预注册清单管理，协议不会读取分组后改变策略。

## 1. 完整固定扫描

先使用既有、有证明的覆盖点集和固定路线：问题 3 为 7 点；问题 4 默认三角网格 950 m，共 31 点。覆盖路线在构造函数内冻结，`coverage_sha256` 记录标准 JSON 的 SHA-256。

每个站点严格按 **1,2,…,20** 逐频道测量，已经发现的频道继续测量。全扫描结束前不调用完成判据，不因发现或 near 改变顺序，不清除任何源。因而问题 3 正好有 140 次覆盖测量，问题 4 默认正好有 620 次；这两个数量不包含协议重试，因为同 request_id 的重试不是新观测。

`near` 的 5 m 外包约束正常进入观测账本，原位置另存 `deferred_near`。由于源尚未清除，后续同点复测仍应获得同一测量类别及示向读数。每个测量都带覆盖站点索引，只有全部 20 个频道的索引集合与完整路线一致，才将 `coverage_completed` 置为真。

## 2. 抽样与冻结参考集合

全扫描结束后，对所有状态为 detected 的频道升序排列，执行

```python
random.Random(survey_seed).sample(sorted_detected_channels,
                                min(sample_count, len(sorted_detected_channels)))
```

这是不放回简单随机抽样，抽到的列表顺序也是访问频道顺序。在覆盖条件及观测模型成立时，扫描已发现全部目标；实现仍只读取已观测到的频道，不读取真实目标清单。用于跨环境重放时，应记录 Python 版本以及实际 `sampled_channels`，不只保留随机种子。

在第一条追加观测前，**一次性冻结所有抽样频道的参考集合和全部预定点**。每个频道参考记录包含：

- 截至覆盖结束的完整观测账本及保守凸外包顶点。
- 外包的最小包围圆圆心 `estimate` 与外包半径 `outer_radius_m`。
- 第一条正观测（direction 或 near）的位置与账本索引，作为复测锚点。
- `estimate_is_ground_truth=false`，明确圆心只是估计，未把估计位置当作真值。

所有预定点的标准 JSON 用 `plan_sha256` 识别。之后的正观测、无信号、near、外包收缩，均不改变抽样对象、中心、测点或访问顺序。问题 4 也不根据先出现的无信号转向；避免把自适应选择混进固定调查样本。

## 3. 追加测量设计

方位采用东向为 0°、逆时针增加；不推断源的真实发射朝向。半径都是相对冻结估计点的**名义距离**。

| 项目 | 问题 3 | 问题 4 |
|---|---|---|
| 名义半径/m | 600、1100、1450 | 600、1200 |
| 每圈名义方位 | 0°、90°、180°、270° | 0°、45°、…、315° |
| 环上测点 | 12 | 16 |
| 原正观测位置复测 | 2 次 | 1 次 |
| 邻点 | 原锚点东侧 1 m、北侧 1 m，各 1 次 | 同左 |
| 每抽样频道总追加数 | **16** | **19** |
| 标准抽 2 个频道的追加数 | **32** | **38** |

访问次序为半径升序、各圈方位升序，然后原锚点复测、东邻点、北邻点；问题 3 最后再回到同一锚点。问题 4 的单次追加复测与覆盖阶段原观测构成一对同点数据；原正观测锚点使这对数据即使面对定向源也保持原先可见条件。若原观测是 near，则只能检查类别一致性，不能虚构示向角。

题目中真实接收半径在 1000..1500 m，问题 3 的多距离设计用于积累范围信息；问题 4 的两圈多角度设计用于积累类型、方向和可见范围信息。它们是预先固定的实验设计，不保证某个具体点一定能收到信号，也不是宣称最优的实验设计。邻点可能穿过接收/定向边界，导致观测类别改变；不能把所有这种变化解释为示向误差变化。

令冻结圆心为 c、外包半径为 r，实际预定测点为 p。日志逐点记录实际坐标、生成偏移、名义方位、d=|p−c| 和保守距离区间

\[
\max(0,d-r)\le |p-g|\le d+r.
\]

该区间保留估计不确定性。可据此做截断/区间推断，不能直接将 d 视为真实测距，或把相对 c 的角度残差视为真实仪器误差。若测点恰好与圆心重合，名义方位未定义，记录为 null，实际复测动作照常进行。所有追加测量期间仍禁止清除，`_clear` 有阶段守卫。

## 4. 清除与结束条件

全部预定追加动作确认完成后，才进入 cleanup，复用基类 `_joint_service(force=True)`、`_localize`、外包顶点认证、110 点有限光学后备和 `_complete_evidence`。

此前 near 对应的外包已与 5 m 圆外包相交，其包围圆远小于 19.999 m，因此即使从未得到过 direction，仍可由基类外包证书直接清除。清除点必须对整个保守外包成立，不直接清除未经认证的冻结估计圆心。cleanup 中新的 near 可按原策略立即清除。

完成仍须具有 16 个不同频道成功清除确认，或“已发现者全部清除，其余频道完整覆盖未发现”的证据。全部扫描、全部追加和清除证据三项同时成立才返回 `status=complete`。若确认清完但 `/exit` 未确认，沿用 `complete_exit_unconfirmed` 区分，不能当作接口全过程已确认。

## 5. 日志及不完整状态

每个测量决策含 `phase=coverage|survey|cleanup`、`station_id`、`target_channel`、实际 `position`、完整确认 `response` 和更新后的 `knowledge`。

- 覆盖站点：`coverage:000` 等，同站 20 个频道共享标识。
- 追加站点：`survey:07:00` 等，包含频道及该频道的预定动作序号；附 `measurement_design` 与参考估计/半径/计划散列。
- 清除阶段的主动测向：`station_id=null`。
- 默认保留客户端历史时另含实际确认请求的 `request_id`；`keep_history=False` 时该字段为 null，此时使用响应虚拟时间、目标频道、位置与客户端接受日志匹配。

`survey_plan` 决策记录完整参考与设计。`start` 记录完整路线、固定频道顺序和先扫描后清除要求。`phase_stats` 给出分阶段测量/清除计数及起止虚拟时间。

预算不足、协议错误、观测不一致会返回 **incomplete**，保留错误与执行到的阶段。`coverage_completed`、`extra_survey_completed`、`survey_sampling_complete` 和 `cleanup_complete` 分开记录；例如追加阶段中途耗尽预算不能记成完成调查，也不会提前清除剩余目标来掩盖缺失测量。既有预算检查之外，还检查 `/enter` 广播的虚拟时限。含不确定 pending 请求时，不发送新清除或 `/exit`，以免重复执行。预算耗尽不等于完成，不能将不完整案例从总体成功率统计中删除。

固定 coverage 矩阵可在相同问题、路线散列、协议、阶段、站点之间比较。追加样本依赖观测估计，比较时还必须使用设计与不确定范围；不得将 baseline 的自适应测量缺失项补为无信号。题设同点误差固定，复测用于一致性检查，不构成独立噪声样本。

## 6. 合法坐标与虚拟时间上界

以下只对标准 `sample_count=2`、基类终止文档列出的 M≤45、L≤5、ε≤1.06° 配置成立；墙钟时间仍受计算/网络影响，不能由虚拟时间证明。

初始圆 128 边外包及其子集的包围圆圆心距原点小于 1801 m。环上点半径最多 1450 m，故距原点小于 3251 m。复测锚点是覆盖点（统一界 2800 m），邻点只加 1 m。因此所有标准调查点都在原点半径 R_s=3300 m 内，远低于每坐标分量 2,000,000 m 的接口限制。

可以在完整扫描的最后覆盖站点处，插入全部 A 次追加测量，然后虚拟地返回该站点，再接上基类全部清除服务。实际代码直接进入清除，由三角不等式，这个额外返回只会放大路程。调查增加的时间满足

\[
\Delta T\le\frac{2(R_g+R_s)+2R_s(A-1)}5+6A,
\quad R_g=2800,\ R_s=3300.
\]

Q3 A≤32，故增加≤43552 s（12.098 h）；Q4 A≤38，增加≤51508 s（14.308 h）。加到 `termination_bound.md` 的相应粗界：

| 标准调查路线 | 基类粗界/h | 加入标准调查后/h |
|---|---:|---:|
| Q3 7 点 | 52.0671 | **64.1649** |
| Q4 三角 31 点 | 60.3338 | **74.6416** |
| Q4 方格 45 点 | 65.1560 | **79.4638** |

仍均小于 100 h。旧基类界直接包含每站至多 20 频道的全扫描，因此这里不重复计算覆盖测量。若某频道覆盖阶段只得到 near、首次方向在追加阶段才出现，它的外包始终包含于原 5 m 近域，cleanup 直接认证清除；不会破坏基类后备起点来自覆盖站的界。其余需后备的源首次 direction 仍来自覆盖阶段。追加正观测只收缩已有外包，负观测不错误删除非凸区域，基类清除和候选坐标界继续成立。任意加密网格、增加 L 或 sample_count 都须重新代入计数，不沿用本表。
