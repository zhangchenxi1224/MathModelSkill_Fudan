# 问题4：围绕完整性证据与剩余清除成本的迭代

本轮响应的是两项已观察到的成本：完整清除后的覆盖尾部，以及大量光学网格清除。它们需要不同的改进与消融。本文给出第一性原理，实际构造、实现与运行结果分别见 `refined_coverage.md`、`refined_local.md` 和本轮实验报告。旧官方日志、基线和已发布候选均保持原样。

## 1. 明确优化对象

任务完成不是估计坐标收敛，而是已经得到所有目标的成功清除确认，并且能够排除剩余频道中仍存在目标的可能性。采用词典序目标：完整性第一；满足完整性后，最小化总虚拟时间；同时遵守现实时间预算。

每次动作必须付出实际移动与调用代价：

\[
T=L/5+N_{switch}+5N_{measure}+3N_{clear}+2N_{success}.
\]

`/clear` 不切频道，失败也会移动。选择测点时的成本为距离/5 + 5 + 是否换频道的1秒。光学覆盖路线的成本必须包含抵达第一个尝试点的路程。

以下量只用于解释，不能分别代替总时间目标：

- 每局 `T/N` 是全部工作按目标数分摊的指标，N较小时完整性搜索开销更难摊薄。
- “最后一次成功清除之后的时间”只能在事后定义。策略不知道那是不是最后一个目标，不能用隐藏N提前退出。
- 故意推迟最后一个目标的清除可以缩短这个尾部而不降低整局时间，因此尾部不作为筛选目标。
- 失败清除次数可以增加而总时间下降；同样，减少失败清除也未必节省总时间。需同时统计移动。

## 2. 未发现频道：到底缺什么证据

对一个从未出现阳性且从未成功清除的频道，已测位置集合为S，反馈均为no_signal。未知目标状态为位置g、固定接收半径R，以及问题4允许的固定发射方向u（也可能全向）。令

\[
D=\{g:\|g\|\le1800\},\qquad
S_g=\{s\in S:\|s-g\|\le1000\}.
\]

在理想精确几何和包含边界的180度发射区模型下，下列条件是排除所有潜在定向源的充要条件：

\[
\forall g\in D,\quad g\in\operatorname{conv}(S_g).
\]

**充分性。** 设g是S_g中点的凸组合。对任意固定单位u，各点相对g的投影的加权和为0，因此至少有一个投影非负。该点的距离又不超过1000≤R，必应返回阳性，与全部no_signal矛盾。s=g时同样必在有效区内并可near。

**必要性。** 若某个g不在非空有限集合S_g的闭凸包内，严格分离定理给出一个单位u，使全部s∈S_g都满足u·(s−g)<0。选取合法固定R=1000，近点均在背面，远点均超距，全部已取得的no_signal同时与这个固定(g,R,u)相容。S_g为空时任意u即可。因此不能排除该状态。这里使用的是一个共同u，而不是对不同观测分别改u。

这个命题也能排除全向源：凸包条件蕴含至少存在距离≤1000的测点。它的适用范围是未知频道且仅有no_signal；有清除失败或其他观测时还可以利用更多约束，但本轮不依赖那些额外推断。

**工程含义。** 31个点只是满足条件的一套构造，点数和路线都不是不可突破的下界。可改变三角网格的平移、间距或路线，但必须重新证明连续目标域都被覆盖。某频道没有真正检测过的位置不能进入它的S。

本轮先优化具有简单连续域证明的静态覆盖，不实现一个尚未认证的任意点集连续域判定器。未来的自适应跳点必须使用同一条件的可靠证书，不能依赖目标数量的经验分布或粗采样图。

## 3. 已发现目标：信息还有多少价值

对已发现频道维护当前外包集合P，保证真实位置g∈P。历史负观测和清除失败可以使真实可行集分裂；当前凸外包可以丢失这些负信息，但不可排除真实位置。

令U_opt(P,s)表示从当前点s开始，按某条已认证有限光学覆盖路线执行直到成功的最坏耗时上界。它包括移动、每次3秒尝试和最终成功额外2秒。若P已能被半径略小于20米的圆覆盖，则优先计算并复核安全清除点。

继续测量的价值不应只用“夹角接近90度”“面积更小”或“包围圆半径更小”表示，而应比较实际剩余秒数。对候选测点q及反馈y，可定义一步上界：

\[
U_{measure}(q)=\|q-s\|/5+5+\mathbf1[f_{current}\ne f]
+\sup_{y\in\{direction,near,no\_signal\}} U(P_y,q).
\]

direction需要覆盖整个可返回角度区间，不能只模拟几个真实位置；near可直接尝试清除；no_signal在问题4中不能随意删除1000米圆盘，可保留P作为安全外包。

若使用相容假设的加权分支概率，则得到的是期望成本启发式，不是确定性概率模型或完备性证明。即使比较的是两套有效上界，较小的上界也不能保证每个实际案例更快，因此仍需配对实验。

还有一个容易忽略的限制。若no_signal分支保持P不变，对真正最优的光学续行成本V_opt有

\[
V_{opt}(P,s)\le \|q-s\|/5+V_{opt}(P,q),
\]

因为光学策略可以直接经过q而不付检测费用。因此，在这个分支下，再付5秒检测通常不可能改善真正的最坏情况最优值。不同近似路线的上界松紧不能伪装成信息价值。本轮可选adaptive实现要求独立证明q可见，之后才比较所有direction/near分支；它可能很少触发，主四臂并不依赖它。若未来要在可见性不确定时积极测量，必须单独验证期望成本启发式，并保留有限清除保证。

## 4. 光学兜底应该使用当前P

原始策略沿首次示向度产生的长条网格搜索，后续仅做有限筛点。首次长条可接近1500米，而多次方向观测后的当前P可能已经很短、很窄。改进应把当前P覆盖，而不是反复支付首次不确定性的成本。

可靠构造之一是方格覆盖：边长h=28米的每个闭方格由其中心20米圆覆盖，因为半对角线14√2<20。保留所有与P相交的方格，计算有限中心集，再优化从当前位置开始的开放路线。必须保守判断相交，包含接触边界，并为旋转及浮点运算留出余量。线段、单点同样用闭集合相交规则处理。

所有真实候选点属于至少一个保留方格，所以至少一个清除中心距真实目标小于20米。若某清除失败，只有能够证明一个候选格完全位于已失败清除圆内时，才可据此安全删除整格；“格中心被排除”不足以删除整格。

网格中心排序不影响完备性，只影响时间。优先减少覆盖中心数和从当前点抵达有效覆盖的路程，之后才考虑更复杂的方向误差概率模型。

## 5. 消融与停止规则

以已经做过官方验证的P4候选为本轮current：NoSignal、L1、joint。旧L5基线仍保留，但不把这次增益与先前6.23%直接相加。

1. current：保持全部旧参数。
2. coverage：只换有证明的覆盖点与路线。
3. local_cover：只换当前P的光学覆盖和路线。
4. combined_cover：同时采用前两项，在各自效果已可区分后考察相互影响。
5. adaptive如实现，则单独预注册，检查追加测量的成本停止；不能把它和光学网格收益混称一个创新。

本地使用相同隐藏环境及固定误差函数进行配对；校准场景、广覆盖合法场景、边界压力场景分别报告。开发选择后冻结候选，用独立新种子确认；失败算失败，不能把失败前短耗时当完成时间。最慢5%在小分层样本内只作描述。

全局停止仍然要求逐频道覆盖证据加所有已发现目标成功清除，或成功清除16个不同频道。统计分布只影响效率决策。所有新方案的官方迁移效果均需新的官方案例；本轮本地结果不能填入官方成绩表。

## 6. 文献使用范围

Zhao、Chen、Lee 的 [Optimal Sensor Placement for Target Localization and Tracking in 2D and 3D](https://arxiv.org/abs/1210.7397) 研究传感器配置几何，包括仅测角情况，正式关联DOI为[10.1080/00207179.2013.792606](https://doi.org/10.1080/00207179.2013.792606)。本轮借鉴的是“选点几何需要评价”的问题意识；上述完整性证书、光学覆盖与整局秒成本比较均需按本题另行推导，不能从传感器配置最优性直接推出单机器狗任务耗时最优。
