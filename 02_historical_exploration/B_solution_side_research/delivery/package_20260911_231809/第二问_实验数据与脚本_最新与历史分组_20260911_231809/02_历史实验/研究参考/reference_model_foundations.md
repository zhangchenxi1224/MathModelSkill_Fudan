# 第二问建模基础：估计坐标、误差半径与测点价值

日期：2026-09-11。本文件保留建立指标时的讨论过程。后续用户认可该讨论并要求记录决策来源、明确目标与约束，现已整理为[第二问当前工作模型](q2_model_spec_20260911.md)：最坏反馈后的最小包围圆半径，实际反馈后输出圆心和误差上界。以下“待讨论／尚未锁定”描述的是当时的决策状态；当前模型以新记录为准。本轮未恢复选点实验，不沿用旧实验的最坏直径排名。

本题依据：[原题](../../B_solution/sources/B题.txt)。外部研究只用于比较建模方法，不增加题设限制。以下数学推导是针对本题所作的推导，不是文献已有的本题求解结果。

**现在要交付的定位结果可以写为“估计坐标 + 保证误差半径”。** 给定首次信息，先选择第二检测位置；收到实际反馈后，更新全部相容源位置，再计算圆心和半径。圆心需要依赖第二次反馈，不能在反馈之前当作已经确定的最终坐标。

## 1. 已知条件和首次相容集合

用全局坐标表示第一点 s₁、首次示向度 θ₁、未知源位置 g、该源固定但未知的有效接收半径 R。源位于 B(0,1800)，此源全向，1000≤R≤1500，测向误差有界于 ±1°。首次已经获得示向度，故 5<‖g−s₁‖≤R。同一地点重复检测的误差不改变。

定义 W(s,θ) 为以 s 为顶点、朝向 θ、两侧各1°的有向角域。首次相容状态为

\[
\mathcal K_1=\{(g,R):\|g\|\le1800,\quad1000\le R\le1500,
\quad5<\|g-s_1\|\le R,\quad g\in W(s_1,\theta_1)\}.
\]

投影到源位置得到

\[
P_1=\{g:\|g\|\le1800,\quad5<\|g-s_1\|\le1500,
\quad g\in W(s_1,\theta_1)\}.
\]

这里没有给目标或误差添加概率分布，也没有将 R 的1000米下界误作源距离下界。源所在1800米圆不限制机器狗测点必须在圆内。s₁不必是原点。

本轮不增加时间成本、移动预算、18点上限、任意最小移动步长或保证第二次必然接收的条件。公共速度和光学参数不自动成为本问的优化目标或精度门槛。

## 2. 第二次反馈必须先完整定义

设新检测位置为 q，d₁(g)=‖g−s₁‖，d₂(g)=‖g−q‖。依据公共设备规则，反馈包含示向度、近距和无信号三种。以下各集合只保留与两次反馈同时相容的状态；第二次不能重新独立抽取一个 R。

**获得示向度 θ₂：**

\[
P_2(q,\theta_2)=P_1\cap W(q,\theta_2)
\cap\{g:5<d_2(g)\le1500\}.
\]

其理由是存在同一个 R 满足 R≥max{1000,d₁,d₂} 且 R≤1500。不同新地点的误差仅用题设范围表示，没有假设统计独立。

**获得近距反馈：**

\[
P_2(q,\mathrm{near})=P_1\cap\{g:d_2(g)\le5\}.
\]

此时所有相容源均在 q 的5米范围内。我们仍可报告该集合的最小包围圆，无须额外执行光学测量，也不把它当作第三次观测。

**获得无信号反馈：**

\[
P_2(q,\varnothing)=P_1\cap
\{g:d_2(g)>\max(1000,d_1(g))\}.
\]

推导：首次示向度要求 R≥max{1000,d₁}，无信号要求 R<d₂。存在同时满足二者的 R，当且仅当 d₂>max{1000,d₁}。因此无信号也有定位价值；不能直接按“目标距 q 大于1000米”更新，更不能删除这个反馈分支后宣称评价全部结果。

空集合对应不可能反馈，不参与评价。若实际收到的反馈导致空集合，须报告数据与模型不相容，不能把空集半径零计作完美定位。

原地重复 q=s₁ 单独处理：在题设的固定误差条件下只重复 θ₁，P₂=P₁；不能用另一份独立测向误差制造信息增益。这里未规定必须移动至少多少米。

记所有可能反馈为 \(\mathcal Y(q)=\{y:P_2(q,y)\ne\varnothing\}\)。角度反馈的允许范围取决于 q 和 P₁，不是简单的 θ₁±1°。

## 3. 已确定尝试的损失：最小包围圆半径

对于实际反馈 y，输出

\[
\widehat g(q,y)\in\arg\min_{c\in\mathbb R^2}
\sup_{g\in P_2(q,y)}\|g-c\|_2,
\qquad
\rho(q,y)=\min_{c\in\mathbb R^2}
\sup_{g\in P_2(q,y)}\|g-c\|_2.
\]

因此，真实源只要遵循题设，就满足

\[
\|g_{\mathrm{true}}-\widehat g(q,y)\|_2\le\rho(q,y).
\]

输出形式为 **(估计横坐标, 估计纵坐标, 误差上界米数)**，并可附完整相容集合及包围圆。这是欧氏位置偏差的界，不是统计意义的估计偏置，也不是95%置信圆。由于近距、无信号存在严格不等式，用上确界；对集合闭包求最小包围圆不改变结果。

这一点估计与 Chebyshev 中心的定义一致：对给定相容参数集合，选择最小化最坏估计偏差的中心。[Eldar、Beck、Teboulle 2008](https://weizmann.elsevierpure.com/en/publications/a-minimax-chebyshev-estimator-for-bounded-error-estimation/)。该论文研究椭球交及半定松弛；本题只借其估计准则，不借用其算法或复杂度结论。

该中心给出的是最好的统一保证，不能保证它比其他估计点更接近每一个具体真实源。它也不等于质心、中心线交点或必然等于直径端点的中点。

对于非凸相容集合，最小包围圆圆心可以不在集合内。这里只要求输出坐标及其误差界，未增加“估计点必须自身是一个相容源位置”的约束；若另加该要求，会形成不同的估计问题。

**终端集合的凸包不会改变其最小包围圆。** 但先对 P₁ 外包、再接收第二反馈，一般会额外保留不相容位置。不能把“终端取凸包无损”误用成“首测外包后所有未来反馈都无损”。若以后用外包多边形求圆，应报告外包产生的保守误差。

任何合法更新满足 P₂⊆P₁，故最小包围圆半径不增。这个性质可作为后续实现的基本检查，不需要给无信号设置任意罚分。

## 4. 尚未确定的另一层：测点如何比较不同反馈

终端圆心已经包含一次对相容位置的最坏误差控制，但这不强制外层再取最坏反馈。固定终端输出后，可以比较以下观测前准则。

| 评价方式 | 对同一终端半径的数学表达 | 所需信息及取舍 |
|---|---|---|
| 最坏反馈半径 | J∞(q)=supᵧ∈𝒴(q) ρ(q,y) | 仅需相容集合；控制任何允许反馈下的最大保证半径，可能为少数差反馈牺牲通常表现 |
| 期望报告半径 | Jπ(q)=Eπ[ρ(q,Y)] | 需要首次信息条件下的源位置、R及测量机制联合概率模型；评价平均可报告精度 |
| 半径分位数或尾部均值 | 如 Qα[ρ(q,Y)] 或 CVaRα[ρ(q,Y)] | 同样需要概率模型，还需要风险水平α；α不是题目给定值 |
| 精度达标概率 | Pπ(ρ(q,Y)≤τ) | 需要概率模型和精度阈值τ；不能擅自取20米，也不是Q3清除比例 |

“期望报告半径”与“真实点估计均方误差”不同。若改为均方误差，则常对应后验均值估计；那已改变用户本轮选择的终端任务。比较外层准则时应先保持同一个 (估计坐标, 半径) 输出，避免同时换掉两个目标。

为了说明偏好差异，假设有两个纯示意测点：A的两种结果半径均20米，B的结果为2米和30米。最坏评价选A；**如果额外给定两种结果等概率**，期望半径选B（16米）。没有这个概率前提，就不能把16米当成B的平均效果。这个例子不是本题算例。

“未知所以均匀”不是无假设做法：按半径均匀和按面积均匀会给出不同权重。平均角度区间也不自动等于平均真实状态，因为反馈角度的发生规律随 q 改变。若只声明概率分布支持在允许状态集上，允许全部这样的分布，那么分布鲁棒的最坏期望退化为普通最坏值；要得到不同折中，仍需额外分布信息。

归纳是：**具有误差分布和先验依据的研究可以采用统计平均或风险指标；只有误差界的研究可以采用集合与最坏保证。** 这是从所读文献作出的比较判断，不意味着现实中所有测向系统都用同一种准则。

Huan–Marzouk明确把实验目的放在定义效用之前，并将成本、资源限制视为依应用另行添加的内容；这也支持本题不自动继承其他任务的时间目标。[作者稿§2.1—2.2](https://arxiv.org/pdf/1108.4146)

## 6. 建议和目前保留的决定

**已确定尝试：** 收到第二次反馈后，用全部相容源位置的最小包围圆圆心作为坐标估计，半径作为位置偏差上界；三种反馈均按题设更新。

**建议优先研究、尚未锁定：** 在不补充概率分布的前提下，评价最坏反馈后的包围圆半径。这是以“可靠控制偏差”为偏好的决策选择，最贴近目前题设信息和用户提出的用途；它不是题目隐含的强制规则，也不保证平均表现最好。

若采纳这一外层准则，完整目标才成为

\[
\inf_{q\in\mathbb R^2}\;
\sup_{y\in\mathcal Y(q)}\;
\min_{c\in\mathbb R^2}\;
\sup_{g\in P_2(q,y)}\|g-c\|_2.
\]

其中圆心 c 在收到 y 后选择，测点 q 只能依赖首次信息；原地重复按固定误差规则处理。未预先限制 q 在保证接收域，也未添加路程或候选数限制。

只有确认外层准则后，才研究怎样比较测点、哪些位置可由信息价值或几何证明排除，以及如何给出有依据的候选区域。届时“保证接收区域”可以作为一个具有额外保障性质的区域单独讨论，不能直接等同整个允许选点空间。
