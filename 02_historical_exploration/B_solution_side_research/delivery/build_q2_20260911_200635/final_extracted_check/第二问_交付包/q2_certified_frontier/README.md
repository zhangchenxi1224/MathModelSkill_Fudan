# 第二问：保证接收的候选区域与精度优先选点

本目录独立于主工程和已冻结的六路线实验。它把第二问从“安全候选加移动成本启发式”推进到“最大保证接收区的闭式推导、精度优先选择、连续响应上界和不可辨识性下界”。已有结论足以支持一套有证明的改进策略；一般情况下的连续全局最优测点尚未求出。

## 数学结论

第一次在 s 得到方向报告 α 后，源位置 g 与同一个接收半径 R 必须共同满足：目标圆约束、5 < |g−s| ≤ 1500、方向误差 ≤ 1°、max(1000, |g−s|) ≤ R ≤ 1500。因此，保证第二次接收到该源的最大区域为

`Q = ∩[g 属于首次可行集 P] B(g, max(1000, |g−s|))`。

完整扇环未被目标圆裁剪时，Q **恰等于四个半径 1000 m 的圆盘之交**；圆心是 `s + r u(α ± 1°)`，其中 r 取 5 和 1000。这不是候选网格上的经验判断，而是充要条件。目标圆发生裁剪时，四圆盘交仍安全，但可能不是最大的区域。

定位指标采用后验可行集的最小包围圆半径（MEC）；它可以直接判断是否已保证进入 20 m 光学范围。同时记录区域直径。对所有合法第二响应取最大半径，然后在保证接收区内最小化，才是本目录的精度优先目标。题目没有规定误差概率分布，因此等权样本平均数不等于官方期望精度。

还有一个严格的能力边界：当 s=(0,0)、首报 0° 时，对任何保证接收的第二点，都能构造两源状态产生完全相同的两次报告，源间距离为 `2 × 1500 sin(1°)/(1+sin(1°))`。因此最坏定位半径至少为 **25.7295668 m**。在保证第二次接收的条件下，无法承诺所有合法场景仅测两次就达到 20 m；这不等于已经求得最优半径。

完整证明及适用条件见 [docs/theory_independent.md](docs/theory_independent.md)。针对一个首次观测的新旧测点严格比较，见 [docs/certificate_comparison.md](docs/certificate_comparison.md)；这是独立数值证书，不是一般连续全局最优性证明。

## 已实现

- `q2_geometry.py`：四圆盘几何、解析径向边界、平移旋转后的安全候选及带余量的数值检查。
- `study.py`：只读首次公开位置和方向进行选点；比较原 fixed、原 active、precision、precision_800 四策略。后两者分别优先最小化保守最坏半径，以及在 800 m 移动预算内最小化该半径。
- 候选先用 1° 响应分箱排序，按各移动预算选入有限短名单，再用 0.25° 分箱细化。它是确定性的有限候选优化，未穷尽连续区域，也未对所有粗候选计算最细界。
- `certificate_audit.py`：从头构造独立的旧点不可区分双源下界、新点全 360° 响应包络上界。证书包含可复算的裁剪多边形及包围圆。
- `docs/official_q2_contexts.json`：20 个官方 P3 survey 局的 40 个首次方向上下文；选点不读取历史第二响应、隐藏源位置或最终清除位置。
- `plot_results.py`：从结果文件生成科学比较图。

理论使用附件规定的返回角误差 1°。选点和实验外包仍使用原工程的 1.0051°，是额外保守量，便于公平比较；不能把它写成题面要求的实际误差。

## 数据与结论边界

旧 Q2 专项仅有 90 个合成场景，第二误差固定 +0.75°。官方首轮有 160 局、46,367 次 accepted 测量，但大量整局数据并不是第二问各策略的直接对照。现有数据能指出远源、小交角等问题，并提供真实首次可行域；没有识别出可直接用于贝叶斯最优选点的源距离、接收半径与误差联合分布。

新增专项覆盖 336 个合成世界，每个运行 4 策略，共 1,344 条结果。世界包含 9 个不同首次公开上下文，覆盖原点、靠近目标边界、目标圆外的首次测点，多个距离，以及两测误差的边界和内部组合。336 个世界不是 336 个独立首次观测，也不是官方随机样本。

另在 40 个官方首次上下文上计算每策略的保守最坏半径上界，按局先平均。新点没有实际执行，因此这些是基于真实首次记录的模型内几何比较，不能称作新策略的官方实测成绩。历史实际第二条方向只作单列诊断；没有用它生成新点的反馈。本次新增官方调用数为 0。

数据来源审计见 [docs/data_support.md](docs/data_support.md)，v2 逐项复核见 [docs/final_audit.md](docs/final_audit.md)。具体结果以 `results/q2_precision_v2/` 为主，`completion.json` 表示运行成功，`run_manifest.json` 记录参与计算的源码 SHA256；v1、v2 均保留对应源码快照。

### 已完成的 v2 对照结果

每策略 336 个世界，共 1,344 条结果，均未丢失信号、真实位置均被后验外包保留。表中半径是后验外包的 MEC 半径；样本最大值不等于连续最坏值。

|策略|平均移动/m|平均定位半径/m|样本最大半径/m|两测后半径 ≤19.999 m 比例|
|---|---:|---:|---:|---:|
|原 fixed|806.23|32.60|78.79|28.87%|
|原 active|437.32|71.27|170.79|30.36%|
|precision|1004.02|26.07|44.85|25.89%|
|precision_800|800.00|33.56|75.26|40.18%|

相对 fixed，precision 平均半径下降约 20.0%，样本最大半径下降约 43.1%，平均多移动 197.79 m；两测后保证进入光学范围的比例略降。800 m 预算版在本设计中的两测成功比例最高，但平均半径略高于 fixed。目标不同，对应的优选策略也不同。

在 20 局、40 个官方首次上下文中，按局平均的**保守最坏半径上界**分别为 fixed 75.88 m、active 160.31 m、precision 52.60 m、precision_800 70.72 m。precision 对 fixed 的这项上界下降约 30.7%；它仍属于模型内的上界比较，不能据此声称官方实际误差下降 30.7%。

独立证书进一步证明，在首次 `(0,0), 0°` 这个上下文中，旧点最坏半径 ≥78.53 m，而新点对全部响应的半径 ≤57.961749 m。这是严格的新旧比较，强于样本平均改善；但对连续最优值 F* 目前只建立了 `25.7295668 ≤ F* ≤ 57.961749 m`，上下界尚未闭合。

全套测试已通过 **20 项**，覆盖接收安全域、角度环绕与误差边界、不可区分双源、响应包围圆和被篡改证书的拒绝。数值计算证书与符号定理各有明确边界，均未宣称形式化证明助手验证。

## 本地使用

在 PowerShell 中运行：

```powershell
Set-Location 'D:\2026WorkExperience\CUMCM2026Problems\B_solution_side_research\q2_certified_frontier'
powershell -ExecutionPolicy Bypass -File .\run_local.ps1 -Workers 2 -AngleStep 5
```

脚本优先使用现有 `D:\st_python\python.exe`，否则查找 python；可用 `-Python '完整路径'` 指定。每次建立新的结果目录，执行合成实验和官方首次几何回放，不访问官方接口。候选更密时可用 `-AngleStep 2.5`；耗时随候选数增加。当前一次 5°、2 进程运行约数分钟，时间取决于本机负载。

也可直接运行：

```powershell
D:\st_python\python.exe study.py --output results/my_new_run --official-contexts docs/official_q2_contexts.json --angle-step 5 --workers 2
D:\st_python\python.exe -m pytest -q
```

研究代码仅依赖 Python 标准库；测试需要 pytest，图形需要 matplotlib 与 numpy，独立高精度证书的依赖及命令见其文档。使用已有 Python 环境即可。输出目录必须为空或尚未创建；不要覆盖已冻结结果。

## 仍需推进的问题

1. 对目标圆裁剪后的真实首次集合求更大的保证接收域，而非只复用完整扇环四圆盘与旧安全候选。
2. 对连续测点区域建立可计算的整体下界，以分支定界等方法缩小最优性差距；加密网格本身不证明全局最优。
3. 分别讨论纯精度、移动预算、20 m 成功率和整局总时间。precision 未必同时改善近源表现与两测即清除比例，不能只展示其平均半径优势。
4. 用未参与选择的新场景作独立确认。现有 fit/development 已用于这次探索，不应再包装成独立确认集。新动作的官方效果需要未来实际执行对应动作才能评价。

这里已经建立可复算的理论、实现与实验起点，尚未声称完成以上四项。
