# 下一轮机制建议（源码核对）

依据是 `synthesis_iteration_20260911` 的实际部署配置、RESULTS、5+5局官方表格及相关源码。本次只分析，不运行新实验、不改现有算法。以下收益都是待验证假设。

## 优先级判断

全清时 `T = D/5 + 5M + S + 3A + 2N`，N 对同一世界固定。最近5+5局中，逐局移动成本占总时间的平均值为 P3 79.22%、P4 77.47%；失败清除分别平均23.6、40.0次。因而多走100米的20秒成本，抵得上约6.7次失败清除。下一轮应优先减少移动与局部服务后折返，不能单纯追求更小定位区域或更少失败清除。

当前强基线应是实际新部署 P3 `p3_r1150_w1`、P4 `p4_L2_d1200_w1`，不能再用旧L5证明改进。已做过的半径权重、测向次数、绕行阈值邻域搜索继续大范围铺开，边际价值有限。

## 1. 用实际清除续程评价补测，优先P4

**源码缺口：** `sensing.py` 仍用 `移动/5+5+w×后验包络半径/5` 作为方向分支成本。`nosignal_sensing.py` 对无信号分支仍按旧110点条带计算，而实际部署已执行旋转 bbox 紧致覆盖。相同MEC半径的细长、紧凑或不规则区域，实际清除成本可能明显不同；旧条带还可能系统性夸大无信号代价。`synthesis.py::cost_gate` 仅比较“直接清除上界”和“补测不可避免成本下界”，门槛极苛刻；它未触发，不能推出一步实际服务成本比较无效。

**具体新机制：** 在现有候选测点中只取前3–4个，增加“现在直接覆盖”作为第0动作。对每个测点的方向/近距/无信号结果，调用与执行端相同的 bbox 清除策略估计继续成本，再比较：

`J(测点) = 到测点移动/5 + 检测5秒 + 切频 + 各结果分支的预计清除续程`。

首次先只替换无信号分支的旧条带代价为 bbox 代价，作为极小消融；之后才加入方向分支的实际覆盖代价和自动决定第2次补测。保留 P3 最多1次、P4最多2次的总上限，仍然完成当前源后才选择另一个源。

方向分支可用4°粗分箱做筛选，入围项再用2°分箱；不能把分箱中点当成唯一可能反馈。预计分支权重仍只是工作模型；固定(g,R,u)与空间误差必须在整个历史中一致，不能把同站重测当独立降噪或重抽误差。概率模型失配时保留完整包络、有限覆盖和原选择器退路。

**区别于已有实现：** `refined_local.py` 已有“保守最坏续程上界”门槛，但它既不是平均服务成本，也没有将当前 bbox 执行器放入方向与无信号的统一排名。不要把上述旧门槛改名当新机制。

**最高价值诊断：** 按补测次序及返回类型统计额外移动、包络长/短轴、bbox尝试点数、实际直到清除的时间；在同一个已记录决策状态上对“立即覆盖/补测”做小规模配对继续模拟。重点判断 P4 的第2次补测在何种合法可观测状态下值回成本。离线分叉必须复制完整固定世界和误差场，不能用官方日志拼造未观测反馈。

## 2. 将实际清除结束位置加入服务排序与清除点排序

**源码缺口：** `scheduling.py::_route_destination` 对未可证一次清除的源使用 hull中心或当前位置向hull的投影，后者可以离实际清除终点很远。清除之后才重新排覆盖站点，不能弥补之前在错误服务终点代理下做出的选择。`cover_order.py` 已存在基于96个均匀工作样本的首击时间排序，但不含清除结束后到下一任务的路程；因此简单启用旧mass排序不算新机制。

**具体新机制：** 对同一完整清除点集的原序、逆序、最近邻等少数排列，在首击时间后增加“命中点到下一覆盖站/下一已发现源”的成本：

`J(排列) = Σ_i p_i [首次在第i点命中的累计服务时间 + β×到下一任务距离/5]`。

服务排序也用同样的预计服务时间和终点分布替换单个 hull 最近点；先固定下一覆盖站作为唯一续程目标，验证后再试最近另一个已发现源。无需展开跨频道反馈树，也无需在多个源之间频繁中断切换。所有尝试点保留；仅改顺序不影响连续覆盖。

可证一次清除时，安全位置本来是一个区域。已有 `nearest_safe_clear` 最小化当前到清除点的距离，可增加“当前→清除点→下一站”的二段路径候选，并对整包络20米条件重新验证。该小消融不需要概率模型，但可优化范围至多几十米，属于小收益项。

**最高价值诊断：** 记录选择时的 hull 投影、实际成功清除位置、清除后下一次全局检测位置，以及两者形成的真实绕行。统计代理误差与后续折返占比；对最差10%服务动作画两段路径，可直接判断是否值得做复杂终点分布。均匀hull质量只是启发式，不能当校准后的真实后验。

## 3. 清除覆盖单元裁剪与中心微调，随后才研究全局站点

**源码缺口：** `clear_cover.py` 已做包络方向选择、各向异性矩形分块、完全不相交单元排除和蛇形/2-opt路线，不能重复提出这些。它尚未利用失败清除圆动态排除已覆盖部分，也没有把单元与 hull 的实际交集拿来移动/合并清除中心。`refined_local.py` 已有精确单元交集和失败排除逻辑，但当前最终部署并未使用该执行器。因此应移植适用部分作消融，不必重新写一套定位框架。

**具体新机制：** 对 bbox 的边界单元计算其与保守 hull 的交集。只有当交集的全部顶点都落在某个20米圆内，才允许把中心向前后路径移动；仅当相邻单元并集的全部顶点仍被同一20米圆覆盖，才合并尝试点。失败后，仅当整个剩余单元均包含于某个已失败清除圆时才删除。这样有机会减少边界冗余与折返，同时保留连续几何保证。

先用局部两点交换/中心朝邻点线段投影，只做1轮；不要为几秒清除节省付出昂贵精确优化。连续覆盖须依赖整个单元的证明，不能依赖96个样本都被覆盖。

**关于P4全局25站：** 当前已是10944个平移格点候选中的几何搜索产物。最新官方P4决策日志中的固定25站证书给出：从原点出发的开路线长为 **24095.423821030687米**，该固定点集路线下界为 **24095.423818749998米**，仅差约 **0.000002281米**。因此，同一25点集、同一原点、遍历全部站点的静态TSP已几乎没有优化空间；不能再把更强TSP求解器作为主要增益来源。这个结论不排除局部清除改变当前位置之后重排剩余站点的收益，也不排除改变几何站点集合的收益。

**较高上限的后续研究：复用实际服务位置，置换未访问的发现站点。** 机器人已经走到测向/清除位置时，评估在那里补扫尚未知频道，能否将该实际位置纳入各频道的发现覆盖证书，并替代尚未访问的某些固定站点。评价应是“未来被省掉的移动与检测时间”，减去“当前位置补扫未知频道的5秒检测与切频、以及覆盖修补导致的额外移动/检测时间”。只有前者更大且逐频道的连续覆盖仍能重新证明，才执行置换。已清除/已判不存在频道无需补扫；不同频道扫描历史不同，不能把某频道的一次正信号当作所有频道的覆盖证据，也不能只凭粒子或少量采样证明删站安全。

先以一个已到达服务位置、置换最多一个尚未访问站点作几何可行性研究，保持完整旧25站作为失败退路。若需要重新三角剖分，须保持1800米圆及外侧微小余量完整覆盖、相关单元最大直径严格小于1000米，以及无翻转/无缺口；当前995米网格只有约5米直径余量，直接小扰动潜力可能有限。此项尚未实现，也不承诺24站、更少站数或一定改善；可以先在既有轨迹上计算可置换机会与净节约上界，再决定是否开发。

未知频道自身的无信号历史可用于轻量排序，但在没有逐频道连续覆盖完成或连续可行域为空的证明时，不能把低概率频道判为不存在、删除必要检测或在已知源数小于16时停止找新源。已失败dynamic方案包含自由逐频道选动作，研究本站点置换时应保留单目标服务承诺，不重做重型跨频道反馈树。

## 小候选表：按项筛选，不做全笛卡尔积

|候选|改动|小参数范围|题目/先后|
|---|---|---|---|
|A0|仅把无信号分支旧条带成本改为实际bbox成本|其余全部保持部署配置|P4第一优先|
|A1|直接覆盖与1步测向→覆盖比较|候选测点3或4；节省门槛10或30秒；总L不增加|P4后P3|
|B1|清除排列加结束位置代价|β=0.5、1.0；仅下一覆盖站|P3/P4并列|
|B2|可证清除点最小化进出二段路径|原最近安全点+少量安全边界候选|B1的小独立消融|
|C1|bbox边界单元裁剪、失败单元排除|仅排除；随后增加1轮中心移动/合并|前两项有结果后|
|D0|实际服务位置补扫未知频道，逐频道重证后置换未访发现站|每次最多置换1站；先计算几何可行机会与净费用|P4后续几何研究|

第一阶段以当前360个固定世界中的分层子集做同场景配对筛选，同时检查最差局；胜出的单机制再组合并跑全360。已有开发/确认数据现在都可复盘，但不能再次称为新验证。最终冻结最多每题一个新方案，再用新生成的同机制世界及少量官方新局验证。不需要为这一步扩大工程审查；保留全清、总时间及最差退步三类结果即可。

不建议继续优先投入：已失败重型跨频道反馈树、盲目共享补测、仅为缩半径而增加补测、仅凭有限采样减少覆盖站、再次用旧弱基线证明收益。新5局与旧10局是不同世界，P4的新5局还含N=16/Nd=1并触发提前停止找新源的特殊低耗时局，不能从两次官方均值直接认定固定百分比提升。
