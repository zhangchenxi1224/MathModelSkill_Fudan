# 从第一性原理改进六条探索路线

本轮目标是把参考资料中的六种思想变成可执行、可区分、可证伪的完整局策略，并为后续本地迭代保存冻结实验设计。证据快照与精确统计来源见 [evidence_audit.md](evidence_audit.md)。这是一套新增研究旁支，不改变正在另一个任务中执行的官方数据采集、校准与分阶段实验。

## 1. 先优化任务成本，再选算法

真实目标是全部清除并合法结束时的 `T=L/5+5M+S+5K+3F`。已有官方基线每题60局中，P3/P4移动分别占84.19%/78.31%，P4局部测向601/2851次无信号。clear失败的本体时间仅占P4的1.98%。因此，“减少失败clear”“增加Fisher信息”“减小坐标方差”都只是可能的手段，不能代替完整时间目标。

一个无需拟合的量纲换算很有帮助：节省一次5秒测向只抵得上25米路程；为了省一次测向多走100米会付出20秒，除非它还显著改善后续行动。整站20频道扫描约119秒相当于595米路程，所以共享停靠可节省移动，但不能为了共享而测完所有已经没有信息价值的频道。

P4最后一个源清除后继续覆盖的尾段均值862.61秒，占总时7.72%。这给出的是“事后知道全部清除”的理想信息价值诊断，并不代表在线策略已经知道最后一个源是谁。跳过尾段必须有新的连续域/逐频道覆盖证书；清除了10个、后验存在概率小、某段没有信号均不足以退出。本轮的joint_route只重排未执行站点和服务顺序，保持全部覆盖需求。

## 2. 保证层与排序层的边界

每个频道只有一个固定源；核心隐状态可写成 `(存在性,g,R,类型,u)`。题面给出的固定坐标偏差还意味着观测误差不能每次重新采样。单狗无需解决无标签目标关联，但必须同时处理搜索、定位、测台选择与清除位置。

所有新增路线继承原来的有向楔形、目标圆/最大距离外包、最小包围圆与最近安全清除点、每频道覆盖清单、16源上界、有限110点光学兜底、动作串行及预算退出。粒子只决定下一步排序，既不替代凸外包也不授权退出。一次实验性clear失败进入原负观测账本，每目标至多一次，之后仍能进入有限兜底。

定向源的 `no_signal` 是“距离超R 或 在背面”。同一假设的R和u必须解释整个历史。逐观测重新选择R/u会把互相矛盾的证据当成可行；把1000米圆从位置域整体删除又会误删背向真源。新增粒子过滤对所有历史共用固定g/R/u，正方位约束与清除失败约束同样必须满足。

## 3. 已实现的六条完整局路线

|路线/标识|本轮实际决策|与参考设想的范围关系|
|---|---|---|
|集合成员 `robust`|原joint_triangular固定核心，局部按direction分支最坏包围半径排序|可靠对照；Q4无信号分支仍由有限兜底处理|
|Fisher `fisher`|对相容工作粒子平均含可接收性的信息矩阵逆迹位置误差代理，加移动/动作秒数|为局部Fisher几何评分，不将CRLB当±1°硬保证，也不声称实现了全局D最优|
|信息增益 `infogain`|对g/R/u工作状态的离散响应信息增益按成本归一，条件噪声熵单独处理|已发现频道局部信念；未实现20频道存在性联合后验或全局贝叶斯搜索|
|短视界规划 `rollout`|第一动作各反馈分别条件化，选择第二动作，再按第二反馈加叶成本；measure/clear同时参与|真正两步条件决策树，局部有限候选；不是完整多频道POMCP，也未训练价值网络|
|路径与共享停靠 `joint_route`|服务后重排未执行覆盖后缀，按预计首个可执行动作衔接成本选目标；原地补测其他有益已知频道|保持连续域覆盖集合与旧索引，未实现任意删点/MILP最优性；每目标共享测向设上限|
|二元清除试探 `probe`|比较现在clear与补测后clear的工作期望成本，失败后更新历史；每目标至多一次非认证试探|比较的是移动+动作+失败后续代价，不是简单“3秒小于5秒”|

Fisher方法的一手方法背景是 [Zhao等的传感器布置研究](https://arxiv.org/abs/1210.7397)。其统计条件不直接成为本题保证。两步条件规划借鉴 [Silver与Veness的POMCP工作](https://papers.nips.cc/paper_files/paper/2010/hash/edfbe1afcf9246bb0d40eb4d8027d90f-Abstract.html) 中信念条件化的思路，本代码没有声称复现其蒙特卡洛树搜索算法。[Loisy与Eloy](https://arxiv.org/abs/2112.10861)在气味搜索中比较信息贪心与任务搜索；其性能数字不用于本题。

信息量与任务收益必须分开：若两个假设物理源完全相同，只有未来误差种子不同，学到误差种子未必有助于接近源。信息路线因此使用 `I(g,R,u;O)=H(O)-E[H(O|g,R,u)]` 的离散工作估计。两步树则直接加秒数；两者都依赖工作模型，故最终只能靠整局配对实验判断。

## 4. 目前数据能支持哪些模型

160局官方数据已经支持组成分布拟合，但不识别接收半径、空间位置分布、发射方向分布和空间误差协方差。P4 fit仅覆盖98种合法(N,Ndir)中的37种，21种只出现一次；development上平滑组成模型NLL=5.5733，宽支持模型=4.6003。不能把估计参数直接提升为“官方先验”。

本轮composition_fit仅使用冻结fit的平滑组成分布来生成外部测试世界；策略本身没有收到该世界的N/Ndir。另设broad和stress池检验先验偏差。粒子层默认方向混合0.5、连续位置/半径/朝向工作提案；它们属于透明建模假设，不是经过官方拟合的概率后验。位置提案在外包凸域采样，再用全历史拒绝过滤；有限样本可能漏掉小区域，低有效样本量时回退原选择器。

本轮开始审计时，同协议机制比较尚未就绪。交付前隔壁任务已更新机制筛选：公开外包与测向记录给出了“所有R=1000”及“所有R=1500”的逻辑矛盾证据；它们不再进入composition_fit。保留的两种代表为mixed半径配correlated150或extreme150误差，状态均为unresolved。半径均匀混合与这两个误差函数仍未被识别为官方生成器；邻近探针没有找到排除证据也不等于验证通过。

最终manifest已保存该机制列表和原文件散列。composition_fit只在这两种未决代表中轮换；broad/stress保留min/max等合法极端，检验算法的适用边界。未来handoff再次更新时，应新建manifest和样本，不能静默更新冻结计划。不能靠调隐藏半径、噪声幅度或方向比例让总时间均值拟合官方，再拿拟合到的时间证明模拟器可靠。

## 5. 计算预算与逐阶段实验

默认每次局部规划64粒子、8候选、0.2秒预算，工作量有上限。预算耗尽时丢弃未完成候选评分并回退原选择器，日志记原因和耗时。固定工作量下算法可复现，但超时率受CPU负载影响，因此必须报告超时回退率和程序时间；同机器各路线按预先随机顺序执行。

推荐先完成六路线开发池，再冻结每题最多一个候选。选择以“无新增失败、各池平均惩罚时间不升”为门槛，按最差池收益排序；若不满足则仍选robust。确认集只执行robust与冻结候选，不能边看确认边替换参数。5%改善在官方60局总预算下未必有足够功效：由fit基线方差估算，80%功效/双侧5%显著性下，检测5%差别约需P3每臂67例、P4每臂48例；这些为规划近似，不是保证。

后续单因素优先次序：①固定路线改局部动作上限L；②fixed方向先验0.25/0.5/0.75；③共享测量开关及移动节省；④扩大候选/粒子预算，考察新增成本换得多少完整时间收益；⑤两步退化为一步的明确消融。跨题不要强求同一个参数或路线。P3环半径1300已有旁支小规模平均收益且尾部退步，保留独立几何消融，不默认混进六路线比较。

GPU目前不进入在线核心。局内动作必须串行，世界/路线间可用多进程CPU；只有后续需要学习动作排序或价值函数时再单独设计训练数据、跨世界划分和GPU实验。
