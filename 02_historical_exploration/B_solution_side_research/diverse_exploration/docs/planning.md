# 有限工作信念与局部两步规划

本模块提供 `diverse.planning.choose_action(knowledge, current, current_channel,
mode, config=None)`。输入只有某频道的观测账本、当前位置和当前频道；输出为
`({'kind': 'measure' | 'clear', 'point': (x, y)}, info)`，或 `(None, info)`。
不调用机器人客户端，不读取环境、目标真值或实测先验，不改写账本。调用者保留
原有认证清除与有限光学覆盖兜底。这里只比较当前目标频道的少量局部动作；不是完整
POMCP，也不是跨频道 POMDP。

## 工作模型与相容性

`belief.py` 中每个粒子固定一个位置 `g`、接收半径 `R`、全向/定向类型及方向 `u`，
并带有一个坐标固定的内部测角误差场。一个粒子必须同时解释所有唯一位置的历史响应
及所有清除失败。Q4 的 `no_signal` 仍表示

\[
\|s-g\|>R\quad\lor\quad(s-g)\cdot u<0,
\]

不会将每次负反馈解释成一个新的半径或方向，也不从凸外包络中错误扣洞。
Q3 只包含全向分量；Q4 连续模型默认包含各占 0.5 的全向和定向先验质量。

透明的工作先验为：位置在当前凸包提案中按面积均匀、半径在 `[1000,1500]`
均匀、定向角在圆周均匀。测角误差的工作模型在唯一坐标上均匀于 ±1°，随后按
两位小数输出；历史相容性沿用账本的 1.0051° 保守余量。**这些都不是已被实测校准的
真实分布。** 位置提案限制在观测外包络内等价于先条件化位置支持；随后完整账本过滤。
连续提案覆盖相容区域的内部，有限粒子不保证覆盖，更不能证明不存在其他可行状态。
退化线段或单点凸包使用长度/点提案，这是单独的极限工作约定。

为减少拒绝率，在每个位置先求所有正观测允许的定向角区间，再按区间长度抽样一个
方向；确定方向后，所有处于可见半平面的负观测共同给出半径严格上界。权重乘上
允许的方向长度比例与半径区间长度比例；全向和定向分量按混合先验质量分配，不因
方向网格数量而重复增加先验质量。再通过冻结版
`ChannelKnowledge.compatible_hidden_state` 检查完整历史。
冻结 `vendor/bsolver/nosignal_sensing.py` 未包含 `joint_feasible_hypotheses`，现有
`compatible_hypotheses` 只有至多 7 个位置的小网格，因此这里使用独立的条件重要性采样。

固定数目的位置提案完成后做系统重采样至 64 个粒子。原提案 ESS、相容数、物理状态
去重数和定向质量全部进入日志；ESS 或不同物理状态不足 `min_particles` 就降级。
罕见分量可能在有限重采样后消失，这不表示其已被排除。未来可用真实数据检验并替换
工作先验；目前没有提供经验先验载入接口，避免把未审核参数当作校准结果。

每个粒子在历史测量坐标精确返回原响应，在新坐标通过粒子种子及坐标哈希生成固定
的有界误差。同一规划树里的重复坐标不会重新抽误差。按反馈条件化时只重新归一化
粒子权重，不重采样 `g/R/u` 或误差种子。清除失败严格排除距离小于等于 20 m 的粒子。

## 四种选择器

| mode | 目标与限制 |
|---|---|
| `fisher` | 对各工作粒子累计唯一方向观测的测角梯度外积，加各向同性正则项；评价新站点后的逆信息矩阵迹。只作局部几何代理，不声称均匀有界误差真正满足 Gaussian Fisher 模型或给出 CRLB 证书。不可见分支不增加测角信息，near 分支采用 5 m 代理。 |
| `infogain` | 将候选动作的 `no_signal/near/direction-bin` 分箱，按物理 `(g,R,u)` 分组，通过固定五点测角误差求积估计 `I((g,R,u);响应)=H(响应)-E[H(响应\|g,R,u)]`，按“即时秒数/信息 nat”排序。噪声种子已边缘化，不奖励区分噪声本身；信息目标仍含半径和方向，有限样本可能夸大物理状态可分性。 |
| `rollout` | 显式枚举第一动作反馈，对每个反馈归一化信念，分别选择第二动作，再枚举第二反馈后评价剩余成本；第一动作可以测向或试探清除。 |
| `probe` | 比较直接试探清除与“补测后按反馈选择清除点”。第一步测量后的第二步只比较清除候选；第一步清除失败后第二步可以测量。 |

真正两步值函数为

\[
Q_2(b,a_1)=c(b,a_1)+\sum_{o_1}P(o_1|b,a_1)
 \min_{a_2}\{c(b_{o_1},a_2)+\sum_{o_2}P(o_2|b_{o_1},a_2)V_0(b_{o_1,o_2})\}.
\]

信息增益中的工作误差求积点为 `(-1,-0.5,0,0.5,1)` 度，梯形权重分别为
`(0.125,0.25,0.25,0.25,0.125)`；在历史同坐标则返回已知确定响应。这是对有界均匀
工作噪声的固定近似，不是实测噪声律。Rollout 仍使用粒子内部的坐标固定误差场，
保持同一模拟世界在重复坐标的一致性。

成功清除分支终止并取 0。第二动作依赖第一反馈，第二动作的起点和频道也是第一动作
执行后的状态。候选测量点复用冻结版 `candidate_points` 的局部候选；第二阶段加入
条件化粒子均值、质量较大的粒子位置等清除候选。因此两步条件化是真实代码分支，
不是在单步公式上改权重。每条树路径最多包含一次非认证清除；实际跨调用的
每目标试探次数由外部 Solver 限制。若外部次数已用完，调用者传入 `allow_clear=False`，
根节点与第二阶段都只比较测量动作。粒子成功率即使为 1，也只表示工作近似中的预测，
不是安全清除证明。

即时成本统一为：移动距离/5，测向 5，测向频道改变另加 1，清除 `3+2*p_success`；
清除不切换测向频道。终端函数 `V0` 使用前往粒子均值的一次清除加上一个随 RMS
离散程度增加的失败后剩余时间代理，公式见 `terminal_cost`。该函数不是光学覆盖
上界，也不是完整任务的预期完成时间；`terminal_weight` 应列入独立消融。

## 默认预算与配置

| 字段 | 默认值 | 含义 |
|---|---:|---|
| `particle_count` | 64 | 重采样后的粒子数 |
| `candidate_count` | 8 | 根节点及每个第二阶段的动作数上限；含清除候选 |
| `planning_budget_s` | 0.20 | 规划总墙钟预算 |
| `min_particles` | 8 | 相容提案数、提案 ESS、不同物理状态数下限 |
| `max_position_proposals` | 512 | 提案上限；实际固定为 `min(上限,max(32,2*粒子数))` |
| `directional_prior` | 0.5 | Q4 定向工作先验质量，必须严格在 `(0,1)`；Q3 忽略 |
| `angle_bin_deg` | 2.0 | 方向响应分箱宽度；整周均分，实际宽度略向下调整 |
| `seed` | 20260911 | 确定性提案与内部误差种子 |
| `terminal_weight` | 1.0 | 非信息增益选择器中的终端/几何代理权重 |
| `fisher_ridge_m` | 1800.0 | Fisher 各向同性正则尺度 |
| `allow_clear` | `True` | 两个规划阶段是否均允许试探清除；外部次数用完应置 `False` |

固定提案数、候选数及遍历次序；只有全量工作在截止前完成才返回最佳动作。
超时将丢弃已完成的部分候选比较并返回
`fallback_reason=planning_wall_clock_budget_exceeded`，调用者执行原
`choose_measurement`。截止检查位于提案和树分支边界，不能中断底层单个几何函数；
实际耗时可能略超过截止，但不会将超时产生的部分排序结果当作完成结果。
同一输入在未超时情况下选择确定；机器、负载、并发造成的超时率差异必须记录。
未知配置键或非布尔的 `allow_clear` 将报错，防止拼写错误静默改变实验含义。
没有相容粒子、样本不足或没有测量候选也显式返回 `None`。

## 已执行验证与后续实验

运行 `python -m unittest discover -s tests -p test_planning.py -v`，17 项测试通过。
覆盖完整固定状态相容性、Q3/Q4 分量、负反馈析取、坐标固定误差、重复历史不增加样本、
清除失败 20 m 边界、各动作成本、第一反馈改变第二动作、清除失败后保留频道、无副作用、
选择确定性、预算降级、两阶段禁止清除及错误配置拒绝；另验证只有噪声种子不同时
物理互信息为零、两个完全可分的等权物理状态得到 `ln(2)` 信息。
其中对两个位置各占一半的构造例，第一测向把信念分成两支，
第二清除位置分别为两个目标位置，并验证了手算的两步期望成本。

一次本机默认参数的单方向 Q4 账本冒烟调用，四种模式均在 0.20 s 内完成。
这只验证入口可运行，不是效果或吞吐基准。官方胜率/平均时间改进尚未证明。
应先执行同场景、同种子、同误差场的配对测试，同时报告完成率、总动作时间、移动距离、
测向数、失败清除数、规划耗时及各类降级率，再独立改变粒子数/候选数/终端权重。
为比较粒子近似本身，先采用充足规划预算；默认 0.20 s 则作为独立运行预算实验。
