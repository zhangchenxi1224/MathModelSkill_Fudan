# 问题4静态覆盖：25站平移三角格

本模块只用题设的目标圆盘半径1800米、最小接收半径1000米及计费规则构造覆盖路线。它不读取任何案例、目标位置、观测、官方结果或误差场。原 `coverage.py`、`strategy.py` 和已冻结结果没有修改。新增接口为：

```python
from bsolver.refined_coverage import (
    refined_directional_route, refined_coverage_certificate,
)
points = refined_directional_route()       # 已排序的25个(float,float)
certificate = refined_coverage_certificate()  # JSON可序列化，含完整有序坐标
```

候选是工程选择，不是覆盖站数或整局完成时间的全局最优解。实际整局收益由后续冻结配对实验判定。

## 1. 固定参数与已获得的改进

令微米为整数坐标单位，比例因子 $U=10^6$。固定近似正三角格基向量及平移为

$$
b_1=(995000000,0),\qquad
b_2=(497500000,861695277),\qquad
t=(497500000,646271458).
$$

整数格点为 $p_{ij}=t+i b_1+j b_2$。它来自边长995米、基本胞元相位 $(3/24,18/24)$；高度及平移只在建立整数格时舍入一次。物理坐标为 $p_{ij}/U$。这些三角形是严格定义的整数坐标三角形，不能把舍入后的高度说成精确无理数 $995\sqrt3/2$。

每个基底菱形保留标准两三角形：

$$
(p_{ij},p_{i+1,j},p_{i,j+1}),\qquad
(p_{i+1,j},p_{i+1,j+1},p_{i,j+1}).
$$

它们完整铺砌平面。最大胞元直径为995.000000203069米。保留与半径 **1800.01米闭圆盘** 相交的全部闭三角形，取全部不同顶点，得到33胞元、25站。站点可在1800米目标圆盘外；题面允许这种移动，全部坐标绝对值远小于2000000米接口上限。

## 2. 未知定向源的第一性原理条件

对于一个始终未清除、测量全部返回 `no_signal` 的未知频道，设全部测点集合为 $S$。给定候选源位置 $g$，定义

$$S_g=\{s\in S:\|s-g\|\le1000\}.$$

在题设闭半平面接收语义下，若 $S_g$ 非空，则没有任何固定朝向可以解释这些阴性测量，当且仅当

$$g\in\operatorname{conv}(S_g).$$

充分性：若 $g=\sum\lambda_i s_i$，则对任意单位朝向 $u$，投影的加权和为0，至少一个 $u\cdot(s_i-g)\ge0$。该点在最小半径内，必须产生 `direction` 或 `near`。必要性：若 $g$ 不在有限闭凸包中，严格分离定理给出**同一个**单位向量 $u$，使全部 $s\in S_g$ 的投影均严格为负；取合法固定半径 $R=1000$，更远测点在接收圆外，全部阴性测量同时成立。$S_g$ 为空时，任何朝向与 $R=1000$ 均可解释。

所以完全排除未发现频道，需要对所有 $g\in D$ 满足上述条件，而不能在每次阴性测量后重新挑一个不同朝向，也不能把定向 `no_signal` 当成整个圆盘排除。本次网格是此连续条件的充分构造，没有实现或声称实现任意测点集的连续域必要充分条件检查器。

下面的证明进一步保证**严格正投影且测点不与源重合**，因此不依赖零向量朝向的接口解释。

## 3. 外扩胞元与实际浮点提交的严格保证

所有整数格点与三角形先定义为精确有理数几何。令外扩宽度 $h=0.01$ 米、$\delta=h/2=0.005$ 米。对任意实际源 $g\in D$ 和任意固定单位朝向 $u$，考虑

$$z=g+\delta u.$$

因为 $\|z\|\le1800.005<1800.01$，完整铺砌中至少一个包含 $z$ 的闭三角形 $K$ 必被保留。将 $z$ 写成其顶点的凸组合 $z=\sum\lambda_i v_i$，则

$$\delta=\sum_i\lambda_i u\cdot(v_i-g).$$

至少一个名义顶点 $v$ 满足 $u\cdot(v-g)\ge\delta$，且

$$\|v-g\|\le\|v-z\|+\delta\le\operatorname{diam}(K)+\delta.$$

这是对圆盘内部、格边、格顶点、圆边界及朝外方向同时成立的证明。保留全部闭相交胞元是构造定义；没有凭随机探测删站。

运行时把整数微米除以 $10^6$，得到实际提交的双精度坐标 $\widehat v$。所有保留顶点的模长小于3000米，IEEE-754转换误差远小于 $10^{-8}$ 米。本模块采用保守向量误差界 $e=10^{-8}$ 米，测试用 `Fraction.from_float` 与精确整数有理数直接核对实际输出误差。因此

$$u\cdot(\widehat v-g)\ge\delta-e=0.00499999>0,$$

$$\|\widehat v-g\|\le995.000000203069+0.005+10^{-8}
 =995.005000213069<1000.$$

实际浮点测点严格位于发射半平面内，且与源的距离严格低于题设最小接收半径，并非只证明名义无限精度坐标。若距离不超过5米，应把 `near` 作为发现；否则得到方向。该证明不假设误差会因复测独立变化，也不依赖每个源的真实 $R,u$。

## 4. 闭三角形相交判定没有浮点容差漏洞

外扩半径直接写为整数微米1800010000，所有三角形坐标、叉积和比较使用Python整数。

先做保守包围盒排除。若原点在三个逆时针闭半平面中，三角形与圆盘相交。否则检查三个闭线段：设 $a,b$ 为端点，$w=b-a$，$q=-a\cdot w$。当 $q\le0$ 或 $q\ge w\cdot w$ 时检查对应端点；当投影位于边内部时，精确比较

$$ (a_xb_y-a_yb_x)^2\le r^2(w\cdot w). $$

因此边穿圆、边与圆相切、顶点与圆相切都保留。只检查顶点是否在圆内是不充分的。外扩是分析证明的一部分，并非用浮点近似来猜哪些胞元相交。

实现枚举 $|i|,|j|\le\lceil2(1800.01)/a\rceil+5$。对任意相交胞元，每个顶点距原点不超过 $1800.01+d$，其中 $d$ 为胞元直径。又有 $0\le t_x<1.5a$、$0\le t_y<b_{2y}$，从

$$|j|\le(1800.01+d)/b_{2y}+1,$$

$$|i|\le(1800.01+d)/a+1.5+|j|/2$$

可见所用整数枚举界严格偏宽；整数高度满足 $b_{2y}>0.86a$，且 $d<a+10^{-6}$ 米。固定候选的界为9。测试还使用每轴额外4层的独立枚举核对没有遗漏，但覆盖证明来自上述解析界，不来自该有限测试。

整数坐标为共享格顶点去重；排序不能舍弃任何不同顶点。内部参数校验还要求舍入后的胞元直径加0.01米仍小于1000米，拒绝缺少接收裕量的近1000米参数。

## 5. 有限搜索范围与最优性边界

本次实际构造了19个间距、每个24×24相位，共10944个几何配置。间距按执行顺序为

`950,960,970,980,990,995,999,900,925,940,945,985,991,992,993,994,996,997,998` 米。

相位为 $(i/24,j/24)$，$i,j=0,\ldots,23$。第一批4032配置耗时约23.19秒，第二批6912配置约41.88秒，仅为本机CPU几何搜索墙钟，不是官方运行时间。构造中的站数介于25与37。对于圆盘目标和原点出发，整体旋转网格、平移向量及已确定的点序列是等距变换，站数和路线长度不变；因此不需要反复搜索相同路线的旋转副本。

搜索首先以纯路线长度筛选：不同格点的最小距离至少为 $a-10^{-6}$ 米，所以任何经过 $M$ 站的开放路线长度至少为

$$L_{\mathrm{lb}}=\min_{s\in S}\|s\|+(M-1)(a-10^{-6}).$$

只有该下界仍可能优于当前最短路线时，才运行冻结的“最近邻+开放2-opt”；两批实际排序27与2个配置。900米格27站取得最短的已搜索路线，995米格25站用更少扫描站降低了本次对照的 $L/5+120M$ 上界。**纯路程剪枝并不等价于对后者成本的完整搜索；不声称25站方案是10944个配置上该成本的全局最小，更不声称连续平移、所有路线或所有覆盖方案最优。** 本次到此冻结，不再根据整局结果继续修改这一静态参数。

对于已经固定的25站，任意开放路径都至少需要24条不同站之间的连接，再加原点到首站的距离。以实际点集最短站间距及最近首站建立保守下界为24095.423818750米。当前路线只高出约 $2.28\times10^{-6}$ 米；所以给定这25个站，排序已经非常接近其可证明的最短路线下界。这不意味着站点布局本身最优。

有限搜索可按以下独立几何代码复现，不发送任何官方请求：

```python
import math
from bsolver.coverage import order_route, route_length
from bsolver.refined_coverage import _construction, _float_points, refined_coverage_certificate

spacings = refined_coverage_certificate()['finite_search']['spacing_values_m']
shortest = math.inf
reviewed = []
for a in spacings:
    for i in range(24):
        for j in range(24):
            vertices, cells, metadata = _construction(a, i, j, 24)
            points = _float_points(vertices)
            lower = (len(points)-1)*(a-1e-6) + min(math.hypot(*p) for p in points)
            if lower > shortest + 1e-7:
                continue
            length = route_length(order_route(points))
            reviewed.append((length/5 + 120*len(points), length, len(points), a, i, j))
            shortest = min(shortest, length)
print(min(reviewed))
```

## 6. 与逐频道停止账本的集成

只能在一个全新策略实例开始任何动作之前替换 `policy.points`。新列表索引为0…24，每个未发现、未清除频道都必须在其全部25站完成有效检测，才能由此构造标为不存在。清除成功和16个不同频道已清除的题设数量上界证据仍按旧策略处理。

不能继承旧局31站的 `coverage_indices`，不能把旧原点测量当成新第0站完成，也不能仅因已找到10个源或最后几站无信号就提前退出。定位过程中对某频道的额外观测不能自动当成未访问覆盖站的记录。

旧策略的停止记录从实际 `points`、`required_point_count` 和各频道索引读取数据，故可以保留原逻辑。旧 `config.coverage='triangular'` 只是类别名，复现实验必须另存本模块完整证书与有序站点SHA，不能让审计按默认三角950重建成31站。

若采用“首次direction后立即110点光学兜底、回到覆盖锚点”的直接构造，总虚拟时间上界为 $7819.084764+16\times948=22987.084764$ 秒，约6.3853小时。它仍然**不是**当前加入主动定位及不同调度后整局策略的耗时承诺。几何保证不承诺HTTP吞吐、20分钟真实期限或实际平均成绩。
