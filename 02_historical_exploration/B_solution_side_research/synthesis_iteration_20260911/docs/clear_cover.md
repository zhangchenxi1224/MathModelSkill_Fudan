# 当前连续外包域的局部清除覆盖

接口为 `methods.clear_cover.build_cover(knowledge, current, mode='bbox', radius=19.999)`，返回按移动顺序排列的中心集合与 JSON 可序列化证书。仅访问 `knowledge.hull` 和首次合法方向观测，不访问数据集真值或工作粒子。保留原 `vendor/bsolver` 不变。

## 第一性原理与证书

清除一次失败收费 3 秒，成功再增加 2 秒，机器人速度为 5 米/秒。已检测到的单个目标如果无需再探测，而由有限清除点覆盖当前所有可能位置，则最迟在最后一点成功。对完整路径的保守成本为

`路径总长 / 5 + 3 × 清除点数 + 2`。

对凸外包集合 H，选择正交坐标轴，把全部顶点投影并向四侧各扩展 1e-6 米，得到矩形 R。凸性保证 H 包含于 R。把 R 均分成 nx × ny 个闭矩形，宽 dx、高 dy。每格到中心的最大距离是半对角线 `sqrt(dx²+dy²)/2`。只接受此值严格小于指定半径的划分。每个格均由对应清除圆完整覆盖，因此所有格的并集覆盖 H。点与线段同样适用；四向微量扩展避免零尺寸除法。证书保存原点、旋转角、矩形边界、划分数、格尺寸、保留格下标与被删格依据，可逐格重建四角验证。

唯一删格规则为 `distance_lower_bound(center,H) > cell_half_diagonal + 1e-6`。距离下界来自包含 H 的单位法向条带：将所有顶点投影得到条带边界，中心到任一条带的距离都不超过其到 H 的距离，取最大值仍是有效下界。证书同时保存这些条带。整格位于其外接圆内，该圆与 H 严格分离，故整格不可能包含真位置。这里没有根据粒子密度、经验概率、失败清除圆的并集近似或离散真值样本删除覆盖。当前实现不利用失败清除历史删格。

默认 bbox 检查首次方向、全局轴和各非退化外包边方向；strip 仅检查首次方向。分别枚举不同横纵分段，允许长条由细长矩形覆盖，不强制正方格。每个候选采用八种横/纵蛇形路线中的较优者；最多六个竞争候选再做最近邻与开放路径 2-opt。所有路径操作仅重排点，不删除覆盖。

原 110 点方案覆盖首次方向坐标下 `[-14,1526] × [-28,28]`，半径界为 `sqrt(14²+14²)`。代码另检查当前 H 是否确实落在该矩形内、所要求半径是否允许使用该方案，才把它加入竞争。以与原代码一致的距离规则筛去清除圆与 H 严格分离的点，保持原端点选择及蛇形顺序。新覆盖按上述完整路径成本与它比较，因此有合格原方案时，返回路线的该成本不高于原方案。此保证关于覆盖到最后一点的上界，不保证每个真实位置的首次命中时间均改善，也不宣称求出了全局最短覆盖路线。

## 集成

1. 原有单点 `outer_hull` 安全清除先执行。
2. 达到局部测量预算后调用 `build_cover`，记录完整证书。
3. 对返回点逐一合法清除，收到 API 的 success 才结束；这些点是覆盖尝试，不能标作单点必然成功。
4. 若构造异常或覆盖执行后未成功，保留并执行原首次方向 110 点保底逻辑，最后仍由原始一致性检查处理失败。证书 `backup_points` 总是保留由首次方向构造的原始 110 点，父策略无需更改原核心。

若实现运行中有新的合法观测导致 hull 缩小，原有覆盖仍然有效；若重建覆盖，必须完整保留相应新证书。不能把已执行点直接删去而不说明它们已经失败排除其圆内真值的语义。
