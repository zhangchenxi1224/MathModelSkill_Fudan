# 当前外包的光学覆盖与保守追加测量

本模块是新迭代的局部策略，未修改任何旧冻结模块，也没有在官方环境中执行。默认 `cover` 模式保留冻结 NoSignal 策略的局部测量选择及次数，只替换后续光学兜底。`adaptive` 是另一个可消融模式，额外评估一次测量后的保守剩余成本；其收益必须由后续独立实验判断。

## 接口与消融范围

```python
from bsolver.refined_local import RefinedLocalSolver, RefinedLocalConfig

solver = RefinedLocalSolver(
    client,
    config=frozen_solver_config,       # P4、joint、local_measure_limit=1
    decision_log=decision_log_path,
    nosignal_config=frozen_nosignal_config,
    mode="cover",                    # 或单独作为另一臂的 "adaptive"
    refined_config=RefinedLocalConfig(
        cell_side_m=28.0,
        max_extra_measures=5,
        min_bound_gain_s=0.0,
        direction_bin_width_deg=30.0,
    ),
)
result = solver.run()
```

- `cover`：保留原 L1 测量与 NoSignal 选点，仅改变光学覆盖中心、中心顺序和失败后的安全跳过。
- `adaptive`：执行相同原有局部测量，然后允许继续测量；**包含原 L1 在内，总局部测量次数最多 5 次**，所以 L1 后最多追加 4 次。`max_extra_measures` 是另一个更小的额外限制，不突破总上限。
- 两模式都继承原全局扫描、联合调度、频道完整性证书、预算检查、HTTP 幂等处理、近距离反馈清除与 `nearest_safe_clear`。不能依据样本数量推测真实 N 提前结束。
- 输入只有公开反馈形成的 `ChannelKnowledge` 和 `RobotClient`；不导入模拟器，不读取源位置、方向、半径、真实数量或环境对象。

公共辅助接口：

| 接口 | 返回 | 用途 |
|---|---|---|
| `hull_cell_cover(hull, start, failed_positions=(), cell_side_m=28.)` | `CoverPlan` | 当前完整外包的有限覆盖及确定路线 |
| `remaining_cost_bound(hull, start, ...)` | `(cost, details)` | 一次认证清除或完整光学覆盖的续行动作成本上界 |
| `measurement_cost_decision(knowledge, current, current_channel, ...)` | `(point_or_none, details)` | 仅在可见性已证时比较追加测量分支成本 |

`CoverPlan.cells` 内部保留有理数形式的交集支持顶点。日志中的浮点坐标仅供检查，不反过来作为删除区域的依据。所有计划函数只读观测账本。

## 为什么使用当前外包

旧方案先用首次方向反馈构造 110 个光学中心，再过滤掉与当前外包明显不相交的清除圆；路线正反仍由最初 110 点的端点决定。新方案直接对每次追加测量之后的完整当前外包 P 构造中心，同时按实际保留中心和当前位置选择路线。

这不等于“取 P 的内接圆再覆盖”。真实目标可能位于细长外包端部、角点或边上，内接区域不能保证包含目标。本实现覆盖的是全部 P。

## 有限覆盖证明与数值处理

1. 使用世界坐标轴，以及与 P 最长边平行的坐标轴，分别构造一个网格方案。旋转轴 u 为提交的有限浮点值；v=(-uᵧ,uₓ)，因此作为精确有理数向量二者严格垂直。坐标变换采用这两个实际向量的精确逆矩阵，不假装它们的浮点模长恰为 1。
2. 将 P 的输入有限浮点顶点转为精确有理数，再取其凸包。凸包包含所有输入顶点，点、线段和顺逆时针输入都可处理。网格包围矩形采用精确极值和向上取整；闭合的最终一行、一列包括最大边界。
3. 网格边长 h=28 米。按行先剪裁横条，再枚举行内可能相交的列，避免逐一遍历细长旋转外包整个包围盒面积。对闭方格与 P 做有理数半平面剪裁，四边额外向外扩展 10⁻⁷ 个局部坐标单位。保留所有非空交集，边界接触不使用严格 `<` 判为无交集。
4. 每个格的中心映回世界坐标，转换成最终发送给客户端的实际浮点坐标。再用精确平方距离核验：扩展格四角到该实际中心的距离均不超过 19.999 米。球是凸集，所以整格以及其中的 P 都被该中心的真实 20 米清除圆覆盖。h√2/2≈19.799 米，留有远大于舍入量的余量；若此独立检查不通过，直接失败，不发送未经认证的中心。
5. 任一真实目标 g∈P 至少属于所枚举的一个闭格。该格交集非空，因此被保留，且其中心到 g 小于 20 米。在清除成功之前按有限中心逐个尝试，必定命中。

这是条件性保证：它依赖原观测模型下 `g∈P` 的外包不变量、目标静止和真实清除反馈语义。它不证明路径最短，也不证明新网格所用的尝试次数一定少于旧 110 点方案。所有格被失败证据排除、覆盖被耗尽或出现预算问题都会明确失败，不伪报成功。异常的大网格超过一百万个包围格时拒绝构造，避免无界资源消耗；正常首次方向楔远小于该护栏。

## 失败清除如何安全利用

一次在 f 的失败清除表示真实目标满足 ‖g−f‖>20。该否定圆通常产生非凸洞，不能用随意半平面把凸外包切掉。

本实现保留原失败位置账本。只有某个格的完整保守交集支持多边形被**同一个**已失败清除圆严格包含，才跳过该格。具体检查其每个有理数支持顶点到 f 的平方距离均不超过 `(20−10⁻⁶)²`；凸性保证整个支持都被包含。真实目标不可能位于这个支持，因此删除安全。没有把若干失败圆的包围盒、凸包或近似并集当成可删除区域。

覆盖计划生成时检查既有失败记录，每次新的失败之后再对剩余格检查。后续跳过中间中心只会缩短原完整路径的行走距离，不能破坏覆盖真实目标的证书。

## 路线与秒成本

每个网格比较两种行列蛇形及其反向，再比较从当前位置出发的最近剩余中心路线；选择完整行程成本最小的一个。两个网格方案也按同一完整成本比较。有限候选路线不是连续路径全局最优解，也不假定目标在中心附近概率更大。

对于剩余 k 个中心和完整行程长度 L，光学覆盖续行上界为：

```text
Uclear(P,s) = L/5 + 3k + 2 + 10⁻⁶k 秒
```

前面的失败尝试每次 3 秒，最终成功额外 2 秒。光学清除不切换接收频道。实际成功可以更早，因此完整行程给出上界。若当前 P 已能由一次清除圆认证覆盖，则优先保留原最近安全清除点，连续成本为移动距离/5+5，而不是强制走格中心。

本地模拟器逐次将移动时间四舍五入至微秒，累计值可能略高于连续几何时间。因此最终代码为每个可能的移动动作增加 1 微秒上界余量；单次认证清除和测量续行上界也各加 1 微秒。真实接口费用、动作日志和结果计数仍按原协议记录，不被这项计划余量修改。测量决策日志分别列出名义测量费用和 `measurement_timing_guard_s`，光学计划列出 `timing_quantization_guard_s`。这同时覆盖每段至多半微秒的舍入，以及本题坐标尺度下远小于微秒的距离计算误差。

## 默认 cover/L1 的整局虚拟上界

以下仅针对本轮冻结参数：P4、三角覆盖默认 950 米、31 站、`joint`、`local_measure_limit=1`、`epsilon_deg=1.0051`、`cell_side_m=28`、不开启已发现频道的额外全局测量，以及默认 `cover` 模式。它依赖公开几何/计费模型及原外包数值不变量；**不是 adaptive、更小网格、其他覆盖间距或真实程序墙钟的统一上界。**

1. 初始外包的顶点距原点小于 1802 米（128 边外接 1800 米圆留有充足余量）。第一次方向之后的 P 同时位于方向角楔和 96 边外接 1500 米圆中。后者外接半径约 1500.80355 米，连同原剪裁余量仍可包在长度 L<1502 米、宽度 w<54 米的旋转长条内。后续反馈只缩小外包。
2. 设世界轴包围盒的宽高为 A、B，则 A+B≤√2(L+w)<2201 米。28 米格的列数 nx、行数 ny 满足 nx+ny≤82，故 nx·ny≤1681。这是有意放松的整数界，不是实测格数。
3. 默认控制流在进入某目标光学兜底之前没有失败光学尝试：认证清除失败会直接报错，near 会直接成功清除，普通格点清除只在这个兜底中发生。故初始 P 的投影覆盖每个占用行，不存在删掉整行导致的蛇形奇偶变化。世界轴保留中心的行蛇形路线，是完整 nx×ny 包围格蛇形路线的子序列；三角不等式给出不超过 `28(nx·ny−1)` 的格间行程。后续失败证据跳过中心，只会再取该已选路线的子序列。代码选取的最佳网格/路线成本不大于这个世界轴可行方案成本。
4. 所有首观测站点范数小于 2750 米（固定 31 点实际最大约 2513.464 米）。NoSignal 的初始种子距首观测站最多约 894.43 米；由 P 的最小包围圆产生的其他种子，中心范数小于 1802 米、最大偏移小于 1202 米。凸组合种子也不超出这些界。因此默认 L1 测点和所有实际机器人位置均在半径 3650 米范围内。保留格中心/认证清除点距 P 至多 20 米；即使为证明而引入一个没有与 P 相交的完整包围格起点，其范数也小于 2600 米。以下把单次测点抵达、光学路线起点抵达、返回前一个全局站点的各段路程统一放宽为 8000 米，覆盖这些情况。
5. 每目标的完整光学续行成本不超过：

```text
Uopt ≤ [8000 + 28(1681−1)]/5 + 3×1681 + 2 + 1681×10⁻⁶
     = 16053.001681 秒。
```

   再为该目标预留一次 L1 移动/测量/切频 `8000/5+6+10⁻⁶` 秒，以及清除后返回此前全局站点的 `8000/5` 秒，得到每目标 19259.001682 秒。返回只是证明用的额外绕路：实际直接去下一个全局站不会比“先返回旧站再按全局路线行走”更长。若一个全局站之后连续服务多个目标，给每个目标都预留返回仍然是放松上界。near 或一次认证清除更便宜，已被这项预留覆盖。
6. 固定 31 站路线经当前公开几何函数独立重算为 29890.896534 米，取小于 30000 米；每站最多 20 次全局测量，总计至多 620 次，每次把测量、可能切频和量化余量取为 `6+10⁻⁶` 秒。

因此最多 16 个目标的整局上界为：

```text
T ≤ 16×19259.001682 + 30000/5 + 620×(6+10⁻⁶)
  = 317864.027532 秒
  < 317865 秒 < 360000 秒。
```

这个界非常松，作用是把“有限”加强为默认计费预算内的保守论证，不应用来预测比赛平均耗时。它没有证明真实程序能在 1200 秒墙钟时限内处理完毕；HTTP 中断、预算保护和协议异常仍须按原失败语义处理。此证明使用实际默认构造与固定参数，不将不适用的配置也标为同样保证。

## 保守追加测量及其局限

默认不使用这一模式。`adaptive` 在原局部测量之后，只考虑冻结 NoSignal 选择器给出的一个 q，不搜索连续位置，也不因本模块而改动原 L1 的选点。下一测量的实际费用为：

```text
Cmeasure(s,q,f) = ‖q−s‖/5 + 5 + 1[current_channel ≠ f]
```

以下两种独立证书之一成立，才允许进一步评估追加测量：

- q 位于历史正反馈站点的凸包中，采用旧模块的精确凸包成员判定；同一个固定可见区域包含这些站点及其凸组合。
- 仅对问题 3，P 中所有顶点距 q 均小于 1000 米并保留边界余量，利用最小接收半径排除 no_signal。

无法证明可见时直接拒绝追加。可以记录保持 P 不变的 no_signal 分支光学上界，但不允许它通过选择不同近似路线制造“测量价值”。原因是对于真正最优光学续行成本 V：

```text
V(P,s) ≤ ‖q−s‖/5 + V(P,q)
```

若最坏反馈 no_signal 不缩小 P，机器人原本就能不测量而途经 q，额外 5 秒不能由信息收益解释。不同可行路线的上界松紧可能违反这种启发式直觉，不能当成严格最坏情形改善证据。

q 已证可见时：

- near 分支：机器人已在 q，清除成本 5 秒。
- direction 分支：用至多默认 12 个 30° 分箱覆盖全部 360° 报告角。每箱将角楔扩展到 `epsilon + bin_width/2 + 10⁻⁷°`，与 P 剪裁后分别计算一次认证清除或完整网格覆盖的续行上界。每个可能报告都属于至少一箱，其真实目标属于该箱的保守外包。
- no_signal 分支：被独立几何证书排除；若真实反馈仍为 no_signal，原账本语义仍保留目标，有限光学兜底继续可用，不会据此宣布不存在。

仅当“移动+测量+切频道+1微秒余量+最坏可见分支续行上界”严格小于立即光学续行上界，且超过配置的最小差额及数值容差，才追加。追加后重新读取真实反馈和新的 P 再决定，硬上限确保有限停止。

**上界之间的改善不等于真实完成时间必然改善，也不是概率意义下的 VOI。** 无校准生成器、无目标位置概率分布，也不宣称排除了其他更好选点；一个较松的立即光学上界仍可能高估真实首次命中成本。可见性限制和粗分箱可能使 `adaptive` 很少追加测量，这应在消融结果中如实报告，不能为了产生收益而放松安全口径。需要模型期望成本的方法应作为另一种明示启发式的新实验，不能混入本轮 `cover` 效果。

## 结果字段与日志

原有 `walk_distance_m / switches / measures / clear_attempts / clear_successes / fallback_targets / certified_clears` 等保持原语义。新增：

| 字段 | 含义 |
|---|---|
| `local_refinement_variant` | `current_hull_cell_cover_v1` |
| `local_refinement_mode` | `cover` 或 `adaptive` |
| `refined_config` | 明示本模块参数；总局部测量硬上限仍为 5 |
| `refined_cover_targets` | 进入新光学兜底的目标次数 |
| `refined_cover_cells` | 进入兜底时各计划保留格数之和；不等于实际尝试数 |
| `refined_extra_measures` | 本模块批准并执行的额外测量次数 |
| `refined_failed_cells_skipped` | 计划前与逐次失败之后依证书跳过的格数 |

`refined_cover_plan` 事件记录中心、网格基向量、路线、尝试数上界和秒成本；`refined_measure_decision` 记录所选点、三分支、可见性证书或拒绝理由、角分箱及费用。真实追加测量仍产生原 `measure` 事件，`reason="refined_local_sensing"`；原 L1 仍为 `local_active_sensing`。清除事件仍用 `certificate.type="optical_grid_attempt"`，额外 `cover_kind="current_outer_hull_cells"`，以保持原计时审计兼容。
