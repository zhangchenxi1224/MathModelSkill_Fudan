# 六路线适配与覆盖证书

入口为 `make_solver(client, config, route, decision_log=None, options=None)`。
`client` 只提供题目公开动作与观测；策略没有环境对象、真实目标总数或目标坐标入口。
默认六路线复用相同 `SolverConfig` 和覆盖坐标。此实现只具备可测试性与安全结构，尚不据此声称某条路线更快。

| route | 本路线改变的决策 | 保持的保证 |
|---|---|---|
| robust | 无；没有环半径选项时直接返回冻结 `Solver` 实例 | 冻结算法全部原语义 |
| fisher | 有限候选的局部信息矩阵评分 | 全外包凸包认证清除，失败可追溯，有限兜底 |
| infogain | 有限候选的观测信息增益 | 同上 |
| rollout | 有限两步行动及清除试探评分 | 同上；每目标最多一次非认证试探 |
| joint_route | 待覆盖路径重排、预计服务动作目的地、共享已发现目标测点 | 原覆盖集与已执行索引不变，每目标共享动作有界 |
| probe | 位置/半径/方向联合可行状态的清除试探 | 每目标最多一次非认证试探，随后仍可认证或兜底 |

概率评分和有限样本只决定候选顺序，不能缩小认证凸包，也不能证明某频道不存在。
规划器返回 `None`、异常、非法点、重复测点或超出试探次数时，回退冻结 `choose_measurement`。
冻结回退也没有候选时，进入首次方位观测对应的有限光学覆盖。

## 行动预算、计时与退出

实验适配器将 `local_measure_limit` 解释为每目标主动行动总格数：新增测量、共享测量和非认证清除试探各占一格。
全局覆盖扫描、认证清除、有限光学兜底沿用冻结定义，不占该主动探索预算。
同一目标最多进行一次非认证清除试探；失败写入原 `failed_clear_positions`，该洞不会被不当地从凸外包多边形中减去。
同地点误差固定，因此距离历史测点不足 0.05 m 的测量提议会被拒绝。

所有实际动作仍经冻结 `_measure` / `_clear` 执行，预算检查在原位置生效。
清除成功收费 5 s，失败收费 3 s，清除不改变当前测量频道；移动费用为距离除以 5 m/s。
有限兜底仍最多检查首次方位带覆盖的 110 个格点，只允许用“整个清除盘与凸外包不交”的几何证明跳点。
继承原 `run()`，因而保留异常、未完成状态、时间残差、停止证据与 `finally` 退出语义。
先前动作响应不明确、`pending_request` 未解除时不会发送退出或新动作。

## joint_route 的路径和共享站点

在每个全局站点完成后，下一站点位置确定未执行后缀的起始索引。仅重排该后缀，已执行前缀与所有已记录 `coverage_indices` 原样保留。
执行开放路径的近邻与 2-opt 排序，从机器人当前位置出发，不强制回起点。每次服务后再计算未执行后缀。
代码检查重排前后的点集和点数相等，并拒绝移动任何已经记录过的覆盖索引。因此不能以优化路线为由漏扫覆盖点。

服务频道按“到预计下一合法测点或认证清除点的绕行/5 + 首动作费用”排序；主动预算耗尽时使用预计首个有效光学格点。
该值只是首动作启发式，不是整个目标服务时间的上界。`joint_detour_m` 仍控制未强制阶段的最大绕行。

共享测量只针对 `detected` 目标，只在机器人当前实际位置执行，且此前没有在该位置测过此频道。
默认每目标最多一次共享测量，可用 `shared_max_per_target` 显式改变；共享动作计入同一 `local_measure_limit`。
默认要求该点的每个方向结果对应的凸外包半径上界降至原半径的 0.9 倍以下，可用 `shared_radius_ratio` 单独调整。
这一筛选不保证定向源可见；`no_signal` 仍是合法结果，并完整进入固定半径、固定方向的原账本。
共享测量不取得额外覆盖索引，不会把已经发现的目标的信息错误转移到其他频道。

## Q3 独立环半径消融的连续域证明

`options={"ring_radius": 1300.0}` 是独立几何消融。默认 `None` 时六路线均使用原 `900√3` 环半径；设置后按比例缩放原有七点顺序，避免对称点浮点并列改变路线朝向。
Q4 明确拒绝此选项，因为距离覆盖不足以证明进入未知定向半平面。

设目标域半径 A=1800 m，接收半径统一下界 c=1000 m，扫描点为原点与环半径 r 的正六边形六顶点。
在六重对称的一个半扇区内，目标极坐标半径 t∈[0,A]，与最近外围顶点夹角 δ∈[0,π/6]。
到最近扫描点的距离平方为

`min(t², t²+r²−2tr cos δ)`。

固定 t 时该量随 δ 不减，故最坏方向为 δ=π/6。两项在 t₀=r/√3 相等。
在 t≤t₀ 段，最近点为原点，最大值出现在 t₀；其余区间的第二项是凸二次式，最大值出现在区间端点。
当 0≤r≤√3 A 时，全连续圆盘覆盖半径严格满足

`ρ(r)² = max(r²/3, A²+r²−√3 A r)`。

两项分别由内部 Voronoi 顶点与圆周扇区中点达到，故不是网格采样结论。
实际证书使用 `ρ(r)+10⁻⁶ m < 1000 m` 的严格裕量检查。
未留浮点裕量的闭可行区间约为 `[1122.955832457922, 1732.050807568877]` m，实际不接受零裕量边界。
任何尚未解决频道在全部七点测量后，若都无信号，即不可能存在合法全向源。
已发现目标仍使用原有限定位和光学覆盖保证；改变扫描环半径不改变首次方向观测的 1500 m 约束。

修改后的逐频道停止证据包含 `analytic_certificate` 和实际扫描点。该证书只证明发现覆盖，不保证仅七次测量就定位到清除半径。
证明思路与既有旁支 `q3_cover_optimization/PROOF.md` 一致，此模块没有导入或改动该旁支。

`python -m unittest discover -s tests -p test_policies.py -v`

这些测试只验证实现契约，不是效果排名或正式测试器等价性证明。
