# 保持完整覆盖的首命中时间排序

接口：`reorder_cover(points, hull, current, mode='mass') -> (ordered_points, info)`，位于 `methods/cover_order.py`。不修改 `clear_cover.py` 或冻结核心。

## 第一性原理

清除目标后即可停止当前频道的局部清除路径。因此走完整条覆盖路线的最坏成本最小，并不等于平均首次找到目标的时间最小。假设第 k 个清除点首次命中的工作概率为 p_k，则平均成功耗时代理是 `sum_k p_k × (截至 k 的移动距离/5 + 3k + 2)`。最后的 2 秒仅在成功时发生一次。

对当前凸外包域生成固定 96 个工作位置样本。正面积多边形按顶点三角扇的面积分配分位点，用平方根重心坐标与固定低差异序列生成三角形内部样本；每个样本都是原顶点的凸组合，必在外包域内。线段使用等间距中点，单点重复该点。不使用真位置、组成标签、H1/H2、世界 ID 或模拟器参数。

这些样本近似“外包域内均匀工作质量”，**不是校准后的后验概率**。外包域可能包含观测排除的孔洞；有限样本也无法代表所有狭窄区域。因此它们只决定点的访问顺序，完全不承担连续覆盖证明。

对每个清除中心预计算其 20 米圆覆盖样本的位掩码。贪心逐步最大化 `新增未命中样本数 / (从当前位置移动/5 + 3)`，每选一点从未覆盖质量中扣除新命中样本。不存在新增样本质量后，以最近邻方式附加所有剩余点。质量为零的圆与重复中心仍然保留。

`mass` 比较原路线、原路线反向、最近邻、上述质量贪心四条候选，选择离散首次成功时间均值最小者，平局优先原路线。故其自身固定样本预测不会比原路线差；不保证真实均值改善，也不保证完整路径最坏成本下降。若输入圆集合遗漏工作样本，返回 `uncovered_sample_count`，评分退化为截尾遍历时间代理，不将其误报为预测成功时间。

`nearest` 单独返回最近邻路线，作为不采用质量近似的消融。

## 连续保证与集成

返回路线是输入索引的严格排列，逐次检查每个原索引出现一次。即使多个原点坐标相同，也全部保留，所以点多重集合不变。原覆盖的所有几何证明继续有效；没有根据样本未出现而删掉任何必要闭集覆盖。

父策略先由原 `build_cover` 构造完整覆盖，再调用本函数。记录原覆盖证书与排序 info；新的 `full_traversal_cost_s` 才是重排后的完整路径成本，不能继续把原覆盖证书中的旧路线成本当成新路线成本。逐点清除仅在 API 确认 success 后停止，原 110 点异常备份保持。

## 计算量与验证

固定 96 样本，掩码构建 O(96n)，两条贪心 O(n²)，四路线评分 O(n)。没有优化器、拒绝采样或不定次数 2-opt。目标适用于常见最多 110 个清除点。

验证命令：`D:\st_python\python.exe -m pytest -q tests/test_cover_order.py`。测试检查所有样本在凸域内、退化与反向顶点顺序、三角形面积采样均值、重复/零质量点完整保留、预测成本逐样本重算、最近邻消融、未覆盖质量报告与非法输入。样本测试只核验工作近似；连续保证来自输入点索引排列不变。

2026-09-11 本机机制计时：110 点、1500×52.6 米矩形、100 次调用，平均 0.0098 秒、最大 0.0164 秒。此例离散预测均值从 460.72 秒降至 355.40 秒，但完整路线成本从 966.15 秒升至 1522.36 秒，直观说明平均目标与最坏目标可能冲突。这里只是合成几何演示，不是 development 或 confirmation 上的效果结论。
