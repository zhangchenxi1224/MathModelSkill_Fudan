## 最新方案是什么

最新方案将 `direction`、`near`、`no_signal` 三种反馈全部纳入两测后最坏定位半径评价。无信号会缩小相容源位置集合，不被视为失败或随意增加罚分。两次观测共享同一个未知接收半径，选点只使用首次公开位置和方向。

几何评价使用圆弧、线段和半平面；通过自适应角区间覆盖合法方向报告，记录候选的最坏半径上下界，再进行有限预算搜索和独立矩形覆盖复核。

**旧“保证第二次一定收到信号”的方案位于历史组。**其25.73米下界有保证接收这个前提，不能直接用作最新允许无信号模型的全局下界。当前有限预算搜索也没有宣称连续全局最优。

## 已有实验数据

最终比较包含8个首次上下文，合并 `mainline_v1` 与 `clipped_geometry_v1`。原点、边缘和圆外等代表场景及官方公开首次几何均有对应文件；center与edge的完整扇环几何等价，不能视作独立困难样本。

已有独立覆盖复核的最坏半径区间示例：

|首次场景|原精度方案/米|新搜索方案/米|
|---|---:|---:|
|center|[55.55,55.73]|[50.12,50.29]|
|outside|[55.55,55.73]|[37.56,37.77]|
|r1-p3-survey-013-ch01|[46.93,47.14]|[41.81,42.02]|

完整8组结果见最终汇总，均保留候选自身的上下界；候选上下界差距不等于连续全局最优性差距。

另有480个合成物理/误差场景、1920条四策略配对记录，全部真值被相应输出圆覆盖。新搜索在该设计中出现30次无信号反馈，均已纳入后验计算。它改善最坏情况，但平均半径没有同时优于全部旧方案。官方首次记录用于模型内评价，没有新测点的官方实测成绩；该轮新增官方调用为0。

## 使用

Python 3.11或以上，在仓库根目录执行：

```powershell
cd 04_Q2/01_最新迭代实验
python -m pip install -r requirements.txt matplotlib
python -B experiment.py --output results/my_new_run --budget 80 --official-cases 2 --workers 2
```

输出目录须为新目录；上述是本地实验，不会发起官方演练。也可使用该目录的 `run_local.ps1`，解释器支持 `-Python` 参数。
