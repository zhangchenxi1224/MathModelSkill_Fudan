# 第二问实验数据与脚本

## 文件分组

- **01_最新迭代实验**：当前三反馈代码与输入数据；主批次 mainline_v1；裁剪场景批次 clipped_geometry_v1；最终复核 final_comparison；PDF、Word、Markdown 最终报告。上述两批共同构成最新迭代，最终对照合计 8 个首次上下文。
- **02_历史实验**：三反馈 pilot_v1 先导实验、保证接收迭代 q2_certified_frontier、原工程早期第二问数据和实验脚本，以及早期研究参考。
- **题面依据**：原题和接口规则的已有文字提取版。

已省去缓存、文档渲染中间文件及与第二问无关的第三、四问整局测试数据。原始工作目录保持不变。

## 运行最新实验

解压后，在 PowerShell 中进入 `01_最新迭代实验` 文件夹：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_local.ps1 -Budget 80 -OfficialCases 2 -Workers 2
```

入口优先使用本机已有 `D:\st_python\python.exe`，否则使用 PATH 中的 Python。需要指定解释器时加 `-Python '解释器完整路径'`。每次运行自动创建新的结果目录。

其他机器建议 Python 3.11 及以上，安装依赖后执行：

```text
python -m pip install -r requirements.txt matplotlib
python -B experiment.py --output results/new_run --budget 80 --official-cases 2 --workers 2
```

运行裁剪场景：

```text
python -B experiment.py --output results/clipped_new --budget 80 --workers 2 --context-ids r1-p3-survey-007-ch03 r1-p3-survey-013-ch01 r1-p3-survey-018-ch01
```

## 先看这些文件

1. `01_最新迭代实验/reports/q2_experiment_report_20260911/第二问实验报告_最终稿.pdf`：最终报告。
2. `01_最新迭代实验/results/final_comparison/RESULTS.md`：最新对照汇总。
3. `01_最新迭代实验/results/final_comparison/verified_comparison.json`：最终候选的上下界与覆盖复核记录。
4. `01_最新迭代实验/results/mainline_v1/feedback_rows.json`：480 个物理与误差组合、1920 条配对记录。
5. `cases/`：各首次上下文的测点、搜索轨迹与分支评价；`inputs/`：首次公开观测及冻结基线。

当前模型允许第二次无信号，并将其纳入最坏半径评价。报告数字属于已有离线实验，未声称全局最优或新测点官方实测。历史实验与最新结果分开保存，不混算。

各已冻结批次中的 `source_snapshot` 保留当次源码；精确重做历史批次应使用其快照。当前根目录脚本用于继续迭代。`finish_results.py` 针对已有 mainline_v1 与 clipped_geometry_v1 汇总并复核；重新运行会更新 final_comparison，请先保留原结果。

早期实验入口为 `02_历史实验/03_早期第二问实现/scripts/research_q12.py`，其中同时包含第一问示例函数，保留是为了保持原脚本及导入依赖完整。保证接收历史迭代使用其自身 README 与 run_local.ps1。
