# P3与P4完整交付

本包将当前算法与历史探索分为两个并列目录。原始文件采用复制整理，没有搬走或改写原工程；没有新增算法实验或官方调用。

## 直接阅读

- `P3_P4_模型与算法实验报告.docx`：可编辑Word报告，公式为原生Office公式。
- `P3_P4_模型与算法实验报告.pdf`：固定排版阅读版。
- `P3_P4_模型与算法实验报告.md`：文本与LaTeX公式源稿。
- `打开查看完整实验记录.html`：1200个最终场景的本地结果和日志索引，以及10局官方表格入口。
- `report_assets`：报告图表、统计数据与生成脚本。

## 两个并列目录

`01_latest_algorithm`：P3 dp_geometric局部两步前瞻，P4 three_feedback_fast三反馈一步决策。包括原始工程全部脚本、配置、数据、各轮候选结果、补跑记录、最终1200场景及官方10局完整日志。原轻量ZIP也随原工程保留，但本目录额外包含轻量包没有收齐的大体积原始记录。

`02_historical_exploration`：完整主线B_solution、历史数据B_datasets、题面与附件B题、其余所有侧线探索和历史交付物。Q1/Q2几何支撑也保留，避免丢失P3/P4算法来源。研究笔记中的未执行设想仍是历史笔记，不代表已验证算法。

`provided_materials`：本次用户提供的两个附件文本。

## 使用最新算法

进入 `01_latest_algorithm`，使用Python 3.10及以上：

```powershell
python -X utf8 evaluate_selected.py --dataset inputs/new240/cases.json --output runs/my_replay --workers 6
```

默认在同一世界运行候选与冻结基线；每次使用新的输出目录。仅运行候选可加 `--no-baseline`。算法和本地仿真所需模块已在vendor及runtime内保存。

官方原脚本保留原路径布局。额外提供 `run_official_packaged.py`，从并列历史目录加载已有演练桥接支持；它需要本机官方模拟器已安装、登录并处于可演练状态，不包含账号登录信息，也不会在打开本包时自动执行。

历史原始报告和JSON内保留了原绝对路径。浏览最终日志请优先使用本包HTML索引，它已映射到包内相对路径。建议解压到较短目录，如 `D:\B34`，避免历史第三方依赖目录触及Windows长路径限制。

## 数据口径

主要基线是p3_r1150_w1与p4_L2_d1200_w1。新240用于迭代，旧960用于回归，两批没有重复世界；不能将其写作未经调参的独立确认。官方本版为P3/P4各5局演练，不是三次正式测试。

全部归档文件的来源和相对位置见 `archive_manifest.json`。归档同时保存失败候选、早期结果和补跑记录，最终采用结果以selection.json与final_*目录为准。
