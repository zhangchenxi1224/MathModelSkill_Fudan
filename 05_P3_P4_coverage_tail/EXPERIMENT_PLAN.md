# 本轮主线

基线为最近官方20局使用的P3 opportunity、P4 count_transit。此前240条继续作为开发集；不运行旧960条。

1. 从最新官方请求和决策日志分解成本。P4最后一个源首次发现后仍平均花2924.76秒，最后一次成功清除后平均花936.50秒。优先减少必要搜索路线及重复访问。
2. 比较原地补测未知频道后替代固定站点、定位不确定性下的延后处理、路线长度限制。按P×H×N快速筛选，每组一场，再将少量候选扩到每题120场。
3. 搜索与具体场景无关的P4覆盖几何。连续位置单元的严格接收/凸包判据验证通过的两圈覆盖，25站搜索路线约17.73km；原三角网25站约24.10km。总任务收益须由完整实验确认。
4. 选型主要看H1各N等权T/N，要求全清且H2整体不退步；同时单列N10—15、N16和最大退步。真N/Nd只用于离线评价，不传给求解器。
5. 候选确定后冻结选型，才在新240条上与同场景基线配对。新数据沿用官方369数量模型比较和320次同协议反馈比较支持的模型：H1主要、H2敏感性；空间、半径、朝向及具体误差机制仍是代表假设。此次更新解决已反复使用的问题，不声称已经提高到官方隐藏世界的精确仿真。
6. 新数据只运行已冻结候选及基线，不根据新数据改选第二候选。确认要求完整清除、H1源数等权平均改善及配对95%区间支持改善、H2点估计不退步；不满足时该题保留基线，并报告候选结果。

保留所有候选结果、请求响应、决策、失败或变慢案例。求解器通过几何或明确的16源上限结束，不使用真值或数量概率提前宣称全清。
