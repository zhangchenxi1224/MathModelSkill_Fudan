# B 题几何算法与认证说明

依据：`sources/B题.txt`、源 `B题/B题.pdf` 第 2–3 页及 `sources/附件2.txt` 第 2.3 节。坐标单位为米，角度从正东逆时针计量。源 PDF 规定测向误差在 ±1°，固定地点重复测量不改变当地误差；附件 2 明确示向度返回值保留两位小数；有效接收半径 1000–1500 m；清除成功只取决于距离不超过 20 m。

本模块不访问模拟器、源真值或隐藏案例。不使用 SciPy、优化求解器或 NumPy，仅依赖 Python 标准库。它负责几何推断和可验证的充分清除条件，不单独承担“已发现所有未知源”的全局覆盖证明。

## 1. 表示与 API

`Point = tuple[float, float]`；`Polygon = list[Point]`，凸多边形顶点沿边界排列、不重复首尾点。单点和两个端点分别表示退化点和线段。裁剪产生逆时针多边形，诊断包含测试也接受顺时针。

| 函数 | 返回及约定 |
|---|---|
| `wrap_angle_deg(angle)` | 归一化至 [-180,180) |
| `unit_from_deg(angle)`、`bearing_deg(origin,target)` | 单位方向；[0,360) 示向度，重合点没有示向度 |
| `disk_outer_polygon(center,radius,n=128)` | 圆的外接正 n 边形，有向外数值裕量 |
| `clip_halfplane(poly,normal,offset,tol=1e-9)` | 与 `normal·x <= offset` 的保守半平面交 |
| `bearing_halfplanes(s,theta_deg,epsilon_deg=1.0051)` | 示向楔形的两边及显式前向约束 |
| `clip_bearing(poly,s,theta_deg,epsilon_deg=1.0051,tol=1e-9)` | 保守测向交会更新 |
| `clip_disk_outer(poly,center,radius,n=128,tol=1e-9)` | 通过圆的切线半平面作保守接收距离截断 |
| `classify_halfplanes(halfplanes,tol=1e-9)` | 无人为边界箱的完整交会分类，见第 3 节 |
| `intersect_bearings(observations,epsilon_deg=1.0)` | Q1 解析入口；`observations` 是 `(测点,示向度)` 列表 |
| `polygon_diameter(poly)` | 顶点对最大距离；空集约定返回 0，不可据此认证 |
| `minimum_enclosing_circle(poly)` | `(圆心,半径)`，半径含极小向外舍入保护；空集抛异常 |
| `nearest_safe_clear(poly,current,radius=19.999)` | 到所有顶点等半径圆盘交集的最近点，或 `None` |
| `certify_clear(poly,point,radius=20.0,margin=1e-6)` | 使用最远顶点距离、实际距离裕量和浮点保护再次认证 |
| `contains`、`distance_to_polygon`、`polygon_centroid` | 凸域诊断、点到区域的距离、面积质心 |
| `max_distance(poly,point)` | 最远顶点距离；空集返回正无穷，避免空集逻辑误认证 |

推荐操作顺序：从目标分布圆外接多边形开始；每次有效示向度做 `clip_bearing`；必要时用 1500 m 最大接收半径的外包做截断；得到清除候选后，对**实际将发送的坐标**再次调用 `certify_clear`。如果可行域为空，进入数据/模型不一致处理，不得直接宣布清除成功。

`no_signal` 不能普遍作为“以该点为圆心删去整圆”的条件，尤其不能用于未知定向源；此类逻辑属于策略层。`near` 则可据题设直接在当前位置请求光学清除，无须虚构示向度。

## 2. 前向测向楔形及角度余量

令测点为 s，读数为 θ，半宽为 ε，要求 0≤ε<90°。定义

\[
u_-=(\cos(\theta-\epsilon),\sin(\theta-\epsilon)),\quad
u_+=(\cos(\theta+\epsilon),\sin(\theta+\epsilon)).
\]

闭楔形由

\[
\operatorname{cross}(u_-,x-s)\ge0,
\quad \operatorname{cross}(u_+,x-s)\le0,
\quad u_\theta\cdot(x-s)\ge0
\]

表示。第三个约束在 0<ε<90° 时冗余，但明确禁止把示向直线背后的反向区域当作可能位置；ε=0 时它把直线限制为射线。使用三角函数方向向量可自然处理 359°/0° 的跨界，不需要将角度区间错误地按实数大小排序。

分析函数 `intersect_bearings` 默认 ε=1°，对应题面误差界。附件 2 明确返回值保留两位小数，但没有单独展开 ±1° 界是否已包含舍入误差。操作函数默认 ε=1.0051°：保守地为四舍五入到 0.01° 另加 0.005°，并加 0.0001° 数值护栏。这是本实现的保护余量，不能表述为新的官方精确误差上界；若 ±1° 已包含舍入，它只是额外放宽。若实际接口明确采用截断或其他量化规则，需据规则重新核对余量，而不能机械套用 0.005°。

固定地点重复检测不会独立缩小 ±1° 误差区间；本模块只做几何交集，不会把重复读数平均后擅自收窄误差。

## 3. 不借助大边界箱的完整半平面分类

一般交集写为

\[
P=\{x\in\mathbb R^2:a_i\cdot x\le b_i\}.
\]

### 3.1 可行性候选为何完备

若 P 非空，原点到闭凸集 P 的最近点必定存在。若原点属于 P，原点就是可行证据；否则最近点位于边界。在二维，若只有一个独立边界法向起作用，它是原点在某条边界线上的正交投影；若两个独立法向起作用，它是两条边界线的交点。因而枚举“原点、各边界投影、各非平行边界交点”，并逐个检查全部约束，可以找到非空多面集的可行点，也适用于无顶点的半平面、平行条带和直线。

零法向约束按 `0 <= b` 直接处理；b<0 时交集为空。所有可行边界交点都是真实有限极点，最后以精确凸包去除重复和非极端共线点。

### 3.2 无界性独立判断

非空 P 无界，当且仅当存在非零方向 d 满足

\[
a_i\cdot d\le0\quad\forall i.
\]

在二维，非平凡衰退锥若有边界，其极端方向位于某个约束的切线方向，即 ±(-aᵢᵧ,aᵢₓ)。无约束或退化宽锥可由额外的四个坐标轴方向覆盖。枚举这些方向并检查所有齐次约束，可判无界，不能由“目前找到有限顶点”推出有界。

对可行点差向量与衰退方向取精确秩，得到仿射维数 0、1 或 2。返回值为：

| kind | dimension | bounded | 含义 |
|---|---:|---|---|
| `empty` | -1 | True | 空集，不能定位/清除 |
| `point` | 0 | True | 单点 |
| `segment` | 1 | True | 有限线段 |
| `polygon` | 2 | True | 有界二维凸多边形 |
| `unbounded` | 1 | False | 直线或射线 |
| `unbounded` | 2 | False | 楔形、条带、半平面或整个平面等 |

**无界结果的 vertices 仅为有限极点，不是整个区域的外包。不得把这些点直接传给清除认证。** 无界交集的直径应报告正无穷，而不是对其有限极点调用 `polygon_diameter` 后报告有限值。

### 3.3 精确谓词与数值坐标的区别

分类器将输入的有限 float 转成 `Fraction`，对这些二进制浮点数所代表的有理系数精确执行可行性、平行性和秩判断。极窄但非零面积的多边形不会因为容差被压扁，矛盾间隙不会因 epsilon 被误当可行。参数 `tol` 为接口一致性保留，并不放松分类器的不等式。

输出坐标最终转回 float，仍受表示精度限制；精确分类针对的是给定系数，不是未知的“理想精确三角函数”。策略层采用带外向保护的多边形裁剪，并在 20 m 距离内留裕量。没有声称整个在线系统使用了精确实数运算。

分类器最坏需 O(m³) 次有理运算，适合 Q1 的少量测点；策略更新使用逐边裁剪，不在每个候选动作上运行精确分类器。

## 4. 圆的外包及裁剪为何保守

半径 R 圆的外接正 n 边形可取顶点半径

\[
R_{vertex}=\frac{R+\delta}{\cos(\pi/n)},\qquad \delta>0.
\]

相邻顶点连线到圆心的距离为 R+δ，因此原圆在其中。若误用顶点半径 R，会得到内接多边形并排除圆周附近的合法源。`disk_outer_polygon` 使用外接构造；`clip_disk_outer` 使用圆的切线半平面，两者都是外包。

若真实可行集 K⊆P，真实新信息为半平面 H，且浮点实现使用 H⊆H⁺，则

\[
K\cap H\subseteq P\cap H^+.
\]

故由外包开始、逐次向外放松裁剪，可保持归纳外包。`clip_halfplane` 先将法向归一化，再将偏移量增加非负距离容差和与坐标尺度相关的舍入保护。它不因法向缩放而改变物理容差，不把相近但不同的极点合并，也不使用“删去极细区域”的启发式。

上述集合包含是在声明的方向/量化误差界内以及有限精度保护有效的计算尺度下成立；默认测试覆盖题目工作区域及约 2×10⁶ m 的接口坐标尺度。若输入溢出、NaN、未知格式或误差界超出配置，不能援引该保证。传给接口前还需重新核对坐标舍入后的清除距离。

## 5. 直径、最小包围圆和反例

凸多边形 P 的任一点是顶点的凸组合。对固定 y，欧氏距离 \|x−y\| 是凸函数，故其最大值可在顶点达到；再对 y 应用同样论证，得

\[
\operatorname{diam}(P)=\max_{i,j}\|v_i-v_j\|.
\]

因此 Q1 用 O(n²) 顶点对枚举即可，免去一般规模下不必要的复杂算法。

直径 d 不保证存在半径 d/2 的覆盖圆。边长 d 的等边三角形直径为 d，而最小包围圆半径为 d/√3>d/2。例如边长 39 m 时，区域直径小于 40 m，但最小覆盖半径约 22.5167 m，不能保证从任何点清除整个区域。

最小包围圆由至多三个支撑点决定。单支撑点为单点圆；双支撑点通常为直径端点；三支撑点为适当外接圆。实现使用固定种子的增量随机顺序、1/2/3 支撑结构和近共线时的有理外接圆后备计算，最后遍历全部顶点将返回半径向外保护。理论背景参见 [CGAL 官方最小包围圆文档](https://doc.cgal.org/latest/Bounding_volumes/classCGAL_1_1Min__circle__2.html)。测试另用小点集所有 1/2/3 支撑的独立枚举作为数值最优性参照。

最小包围圆圆心是一个可用的清除候选，却未必是离机器狗最近的安全点；下一节直接优化移动距离。

## 6. 最近安全清除点

设外包多边形顶点为 vᵢ，采用工作半径 r=19.999 m。全部可能源从 q 都可清除的充分条件为

\[
q\in F_r=\bigcap_i\overline B(v_i,r).
\]

这是对外包 P 的充分条件。因为圆盘是凸的，所有顶点在 q 的半径 r 圆盘内，整个 P 也在其中；真实源在 P 中，因而也在其中。

求解

\[
\min_{q\in F_r}\|q-q_{current}\|.
\]

若当前点已可行，最优移动距离为零。否则欧氏投影落在 Fᵣ 边界；其位置要么在某一个圆盘的光滑圆弧上，此时是当前点到该圆周的径向投影；要么至少两个不同圆周同时起作用，因此是圆圆交点。重合圆只代表一个约束，退化相切点也包含在交点枚举中。

因此候选集为：当前点、每个圆周的径向投影、所有圆圆交点、一个经核验的最小包围圆圆心。逐个检查所有顶点距离，再选择移动距离最小者。候选枚举最坏 O(n²)，所有候选逐顶点认证最坏 O(n³)；定位后域通常只有少量顶点。

浮点圆交点可能微小地落在圆外。若存在严格可行的包围圆圆心，函数利用凸组合将该候选推回可行域，并再次检查，而不放松半径限制。没有通过检查的候选不会返回。`None` 表示未找到认证候选，包括真实不可行和极端数值退化下的保守失败；不能据此断言全部数学情况中严格不可行。

最终 `certify_clear` 采用默认真实半径 20 m、物理裕量 10⁻⁶ m 和额外算术保护。空集始终返回 False。该证书验证**传入外包**覆盖范围，不能修复错误的数据来源、过窄示向误差、无界域误用或过期的定位状态。
